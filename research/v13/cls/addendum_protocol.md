# Post-result endpoint-alignment check

Written **after seeing** the 128-image CLS margin-Spearman result and **before calculating** the additional object-mask endpoints, 2026-11-13. This is an exploratory follow-up, not part of the original v13 CLS protocol or the v12 registration. It evaluates whether the difference between all-query and CLS-only rankings reflects the endpoint and aggregation path rather than a hidden change of image sample or layer.

Use the same 128 independently hash-selected Oxford test images, the same DeiT-S layer-12 five score vectors and the same 196 patch positions saved in `per_source.csv.gz`. Do not make a new model forward or alter score definitions. Load the same trimmed object masks via the spatial study's `PetTest` preprocessing. A mask with no valid object or no valid background patch cannot define object/background AUROC; disclose and exclude that image from **all three** endpoints, including the previously measured margin Spearman, so every reported comparison uses the same effective image set. Preserve the full 128-image CLS analysis separately.

Compute per-image: (1) Spearman between the absolute fixed-class logit-margin change and each score from `per_image.csv`; (2) the repository's same-distance-ring object enrichment; and (3) valid-patch object/background AUROC. Apply the repository `enrichment.measures` implementation to the frozen score maps and masks. Score direction is higher = more important for each endpoint. For each endpoint and each of five scores, report the mean across eligible images and a 95% percentile interval from 10,000 image bootstrap draws, NumPy seed 2026. Use the same draws to report exactly two prespecified paired contrasts: CLS summed-head magnitude minus all-query C3, and CLS net-term magnitude minus CLS summed-head magnitude. Report source-data/selection hashes, eligibility counts, numerical failures, and runtime.

Compare **directions and within-endpoint paired contrasts**, not raw endpoint values across their different units. A reversal between the classification-path endpoint and object-mask endpoints would support a narrower description of what each score reads; it would not establish a general trade-off across datasets or classification accuracy.
