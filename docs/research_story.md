# 研究故事：注意力图到底在说什么？

> **v5 说明（2026-11-05）。** 研究主线已改为 B33 的“读 → 诊断 → 修正”闭环；本文件内容不变。它在 v5 中的位置见 [v5 盘点](v5/inventory.md)。

2026-11-05 · 汇总 v3、补充实验 S1–S3、注意力预算研究的最终可用结果

**一句话：** 我们把 ViT 的注意力从"一张图"变成"一个能用模型自己的输出来检验的测量"；在扣除中心偏差之后，ViT 确实读物体、读动物的头；但注意力里有一大块预算花在少数"停靠点"上，而让注意力图"看起来更干净"的两种做法，只是把这块预算挪了地方，并没有把它引向物体。

---

## 0. 故事结构（三幕）

| 幕 | 问题 | 回答 | 主要证据 |
| --- | --- | --- | --- |
| 一：能不能信 | 注意力图只是一张图，怎么知道模型真的在用它？ | 读出 top-k 读取名单，让模型只按名单计算，预测大多保留 | 执行检验 + T7 对照 |
| 二：读了什么 | 扣掉"物体本来就在中间"之后，ViT 读的是物体吗？ | 是，而且更读动物的头；中后层最像人，最后一层离开物体 | E4–E8、S1–S2 |
| 三：预算去哪 | 注意力是一笔必须花完的预算，花在哪？能不能引向物体？ | 一大块花在少数高范数 token 上；稀疏化和额外 token 都只是挪动它 | 注意力预算研究 T1–T6 |

再加一节**诚实的局限**：作为热图，注意力不如用梯度的 GAE 忠实。

## 1. 出发点：注意力图的三个陷阱

1. **图不是计算。** 注意力高的地方，模型不一定在用。
2. **中心偏差。** 照片里的物体通常在中间，所以任何偏向中间的图都会"看起来"对准物体。
   - 例子：一张固定的、居中的高斯图，和 ClickMe 人类重要性图的相关已经有 0.41，比我们的探针在任何模型上都高。
3. **"看起来更干净"不等于"更关注物体"。** 稀疏化注意力（MiTA）和 register 都声称能让注意力图更干净。但每个 query 的注意力加起来必须等于 1，去掉一处，就一定要流到别处。

---

## 2. 工具：可执行的读取名单（第一幕）

**想法：** 一层注意力等于一个"快权重 MLP"：key 是第一层权重，softmax 是激活，value 是第二层权重，每个 token 是一个神经元（Schlag 等 2021；MiTA）。

**做法：** 按 MiTA 的规则，把 14×14 的图块分成 16 个区域。每个区域用平均 query 挑出得分最高的 16 个 key，这就是这个区域的"读取名单"。模型本身不做任何修改。

**检验：** 让模型的 12 层都只按名单计算，看 top-1 预测还剩多少。

| 模型 | 按名单计算 | 随机名单（同样大小） | 完全没有注意力 |
| --- | --- | --- | --- |
| DeiT-S | **72%** | 9% | 0.1% |
| DINO ViT-S | **62%** | 4% | 0.1% |
| DeiT-B | **83%** | 30% | 0.2% |

**结论：** 名单抓住了模型真正在用的读取，注意力因此可以当作一个"测量"来用。

**修正过的旧证据：** 以前我们用"只替换一层，保留 92%–96%"来证明名单是对的。但直接删掉一整层注意力也能保留 93%–97%（T7），所以单层的数字区分不了"名单对"和"这一层本来就不重要"。现在只用 12 层同时替换作为证据。

---

## 3. 在中心偏差对照下，ViT 读了什么（第二幕）

**统一的对照方法：**
- **同距离环富集：** 只在离图像中心距离相同的图块之间比较。只偏向中间的图得分为 0。
- **图片特异的人类一致：** 和本图人类图的相关，减去和别的图的人类图的相关。固定的先验图得分为 0。
- **中心配对删除：** 删掉物体图块，与删掉离中心同样远的同样多的图块相比。

**结果（三个模型、三种注意力读取方式都成立）：**

1. **读物体，不只是读中间。** 所有注意力读取的同环富集都大于 0。例如完整注意力：DeiT-S 0.140，DINO 0.199，DeiT-B 0.080。
2. **物体移走，注意力跟着走。** 把物体往角落移 48 像素，探针的物体占比下降得比中心图少：DeiT-S、DINO、DeiT-B 分别少降 0.021、0.053、0.010。
3. **模型确实依赖物体本身。** 删掉物体图块的效果，在和离中心同样远的图块比较后，仍保留 63%–79%。
4. **和人一致，而且是逐图一致。** 图片特异的一致都大于 0（完整注意力：0.156、0.208、0.107）。
5. **更读、也更依赖动物的头。**
   - 删掉头部 4 个图块，比删掉身体 4 个图块更伤预测：DeiT-S +0.017，DINO +0.021，DeiT-B +0.008；四足、两足动物上是 2–3.4 倍。
   - 注意力读取对头部的偏好都大于 1。
6. **逐层看：中后层最像人，最后一层离开物体。**
   - 最像人的一层：DeiT-S 第 9 层，DINO 第 11 层，DeiT-B 第 6–10 层。
   - 有监督模型第 12 层明显下降（ClickMe：DeiT-S −0.086，DeiT-B −0.116），DINO 降得少（−0.032）。
   - 三种读取方式的逐层曲线相关 0.77–0.99，所以这是模型本身的性质，不是探针造成的。

## 4. 注意力预算花在哪里（第三幕）

> 这一幕来自注意力预算研究：7 个模型、11,919 张图，所有假设和门槛都在运行前登记（B27–B32）。

**新增的模型：** DeiT-T、DeiT-III-S，以及用 top-k 训练的 MiTA-DeiT-S/T。7 个模型统一预处理，准确率都复现了公开数字。

### 4.1 一大块预算花在少数高范数 token 上

| 模型 | 第 11 层预算：物体 / 高范数 token | 有没有高范数 token |
| --- | --- | --- |
| DeiT-S | 40% / 5% | 少量 |
| DeiT-B | 29% / **43%**（只占 3% 的图块） | 有 |
| MiTA-DeiT-S | 26% / **50%** | 有，最多 |
| MiTA-DeiT-T | 44% / 31% | 有 |
| DeiT-T、DeiT-III-S、DINO | — / 0% | 没有 |

**这些 token 在做什么？** 以 DeiT-B 为例：
- 不让任何 query 读它们，比不读同样多"最受关注的普通图块"更伤预测（0.052 对 0.037 nats），所以这块预算**被用上了**。
- 把它们的 value 换成数据集平均值，几乎没有影响（−0.005），而且它们的 value 很短，只有普通图块的 0.23 倍。所以它们带回的内容像一个**常数项**，不是这张图特有的信息。

### 4.2 两个"让注意力更干净"的杠杆，都没能把预算引向物体

**杠杆 A：训练时稀疏化（top-k，MiTA）**
- 按注意力图平常的画法（不扣任何图块），两个 MiTA 模型都比各自的 DeiT **更不**聚焦物体（−0.039、−0.020），因为 top-k 训练制造了更多高范数 token。
- 扣掉高范数 token 后：Small 组 −0.011，Tiny 组 +0.037。效应方向依赖模型规模，不能说"稀疏化让 ViT 更聚焦物体"。
- 复核 MiTA 图 4："深层只剩少数 token、集中在物体上"的印象，用同样画法看普通 DeiT 也有，而且更强（扣除中心偏差后的富集：DeiT-S 0.092，MiTA-DeiT-S 0.058）。

**杠杆 B：测试时把制造高范数 token 的神经元移到一个额外 token（Jiang 等 2025）**
- 在 DeiT-S 中找到了 8 个这样的神经元（第 4–5 层）。把它们移走后，高范数 token 减少 92%，准确率完全不变（79.83%）。随机神经元和激活相当的神经元都做不到这一点。
- **腾出来的预算去了哪？** 第 9 层：额外 token +5.9 个百分点，物体只 +0.5 个百分点。物体聚焦只提高 0.006，远小于事先定的 0.03。
- 这和 Fesser 等 2026 的发现一致：register 只是把 sink 挪了个地方。
- 在 DeiT-B 中找不到少数几个这样的神经元（32 个只减少 45%），这本身也是一个发现。

### 4.3 最后一层离开物体，不是高范数 token 造成的

扣掉高范数 token 后，7 个模型第 12 层的物体富集仍然都下降，包括 DINO（−0.057）。加了额外 token 后，下降也还在。原因仍是开放问题。

## 5. 诚实的局限和负面结果

1. **作为热图，注意力不如梯度方法忠实。** 删图块检验（SRG）中，最好的注意力读取比 GAE 低 0.10–0.14。例如 DeiT-S：完整注意力 0.242，GAE 0.343。连居中高斯图都有 0.10–0.14，可见中心偏差在忠实性指标里也有影响。
2. **top-k 截断不会让热图变好。** 探针图和完整注意力图几乎一样（逐图相关 0.90），完整注意力在多数指标上相当或略好。top-k 的价值在于"可执行、可检验"，所以论文用完整注意力画图，用读取名单做检验。
3. **每个模型只训练过一次**，区间只反映图片之间的波动。MiTA 和 DeiT 由不同的人训练。
4. **深层 token 不再精确代表原位置：** 第 12 层只有 15%–25% 能被认出原来的图块。
5. **部件实验的图片来自 ImageNet 训练集。**

**预测对账：** 32 条事先登记的有方向的预测中，20 条成立，7 条部分成立，5 条不成立；不成立的都如实报告。

## 8. 讲给别人听的版本（30 秒）

> 注意力图是看 ViT 最常用的办法，但它只是一张图，而且很容易被"物体在中间"骗。我们从预训练 ViT 中读出每块区域的读取名单，让模型只按名单计算，预测大多保留，所以注意力可以当测量用。扣除中心偏差后，ViT 确实读物体、读动物的头，中后层最像人。但深层有一大块注意力被少数高范数 token 吸走；稀疏化训练和测试时 register 都只是把这块注意力挪到新的停靠点，并没有引向物体。所以，一张"更干净"的注意力图，本身不能证明模型更关注物体。
