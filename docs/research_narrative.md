# 研究叙事稿：用读取模式解释 ViT 的注意力

Oct 24, 2026 · @Kevin

这份稿子用七段讲完整个研究：从问题出发，到洞察、方法、检验，再到发现和结论。每一段开头的粗体句是这一段的核心，后面按顺序把故事讲清楚。实验结果还没出来的地方用【待填】标出。

## 一、起点：注意力为什么读不懂

**ViT 看一张图，会产生约 280 万个注意力数值，没有人能直接读懂。**

以 DeiT-S 为例：输入 224×224 的图片，切成 16×16 的小块，得到 14×14 = 196 个 patch token，再加 1 个专门用来分类的 CLS token，一共 197 个 token。

在每一层、每一个 head 里，每个 token 都要决定从其他 197 个 token 那里各拿多少信息：

```latex
A = \text{softmax}(QK^\top/\sqrt{d}),\quad \text{out} = AV
```

A 是一个 197×197 的矩阵，第 i 行表示“第 i 个 token 在读谁、读多少”。DeiT-S 有 12 层、每层 6 个 head，所以一张图片对应约 280 万个注意力数值。

这些数里藏着“模型判断这是一只狗时，到底在看哪里、哪些区域在互相交流”的答案，但没有人能直接读懂这么多数。

## 二、问题：热图不够用

**现有方法把注意力压成一张热图，但热图丢失了“谁在读谁”的结构，而且没法检验它是否忠实。**

最常见的做法是只取最后一层 CLS 那一行的注意力，画成一张“模型在看哪里”的热图；也有方法把各层的注意力矩阵连乘起来，比如 attention rollout。

这样做有两个问题：

1. 丢失了结构：热图只说明“哪里重要”，不说明“狗头区域在读哪里、背景区域又在读哪里”；
2. 忠实性难以检验：一张热图看起来很合理，不代表模型真的按它在计算。“注意力能不能当解释”至今仍有争论。

所以我们想要的是一份关于注意力的说明：它要足够短，让人读得懂；还要能被检验，证明它真的反映了模型的计算。

## 三、洞察：注意力是一个临时的 MLP

**注意力是一个临时搭建的 MLP，每个 token 是其中一个神经元；而且很多 query 激活的是同一小组神经元。这两点来自 MiTA 论文，是整个研究的出发点。**

先看第一点。普通的两层 MLP 是：

```latex
y = W_2\,\sigma(W_1^\top x)
```

输入和第一层权重的每一列做点积，过激活函数，再用第二层权重加权求和。注意力做的事情完全一样：query 和每个 token 的 key 做点积，过 exp 再归一化，用 value 加权求和。所以注意力就是一个两层 MLP：key 是神经元的输入权重，value 是输出权重，每个 token 贡献一个神经元，隐藏层宽度就是 token 数 197。

区别只在于，FFN 的权重训练完就固定了；注意力的“权重” K 和 V 是由当前这张图片临时算出来的，换一张图就变了，所以叫“快权重”。

在这个视角下，“token i 在读谁”就变成了“输入 i 激活了哪些神经元”。

再看第二点。MiTA 发现，很多 query 激活的其实是同一小组神经元：只让每个 query 读一小组共享的 top-k token，模型依然能正常工作；把用普通注意力训练的模型在推理时直接换成这种形式，精度能保留 95% 以上。

如果真是这样，我们就不需要为 197 个 query 各写一份说明，只要写少数几份就够了。基于这两点，我们的方法分两步：先读出一份说明书，再检验它。

## 四、方法第一步：读出说明书

**把图片分成 m 块区域，每块区域取平均 query，找出它最想读的 k 个 token。这些读取集合合起来，就是这一层注意力的说明书。**

读取分四步，在每一层、每个 head 里单独进行，不改动模型：

1. **划分区域**：把 14×14 的网格分成 m 块，比如 m = 16 就是 4×4 块。
2. **算 landmark**：把每块区域里所有 patch 的 query 取平均，得到代表这块区域的 query：q̃\_r = 区域内 q\_i 的平均。
3. **找读取集合**：用 landmark 给全部 197 个 token 打分，取分数最高的 k 个，记为 S\_r。
4. **分配 query**：每个 query 被分给和它最相似的那个 landmark。它不一定被分到自己所在的区域。

第 3 步有一个很好的性质。点积对 query 是线性的，所以：

```latex
\tilde q_r \cdot k_j = \frac{1}{|R_r|}\sum_{i \in R_r} q_i \cdot k_j
```

也就是说，landmark 的分数正好等于区域里每个 query 分数的平均。读取集合的含义因此很直接：这块区域作为一个整体，最想读的 k 个 token。

举一个最小的例子。4 个 token 排成一行，分成两块区域 A = {1, 2}、B = {3, 4}，k = 2：

- queries：q1 = (3, 1)，q2 = (−1, 1)，q3 = q4 = (1, −1)
- keys：k1 = (1, 0)，k2 = (0, 2)，k3 = (2, 2)，k4 = (0, −1)

两个 landmark 分别是 A = (1, 1)、B = (1, −1)。A 对 4 个 key 的打分是 (1, 2, 4, −1)，正好是 q1 的打分 (3, 2, 8, −1) 和 q2 的打分 (−1, 2, 0, −1) 的平均；取最高的两个，S\_A = {3, 2}。B 的打分是 (1, −2, 0, 1)，S\_B = {1, 4}。

说明书读出来就是一句话：区域 A 在读 token 3 和 2，区域 B 在读 token 1 和 4。原来的注意力是 16 个数，现在只需要 4 个编号。放到真实的 DeiT-S 里，m = k = 16 时，一层一个 head 的说明书只有 256 个编号，而原来有约 3.9 万个数。

## 五、方法第二步：检验说明书

**强制模型只按说明书计算。如果它的预测不变，就说明说明书已经包含了模型需要的信息。**

检验的办法很直接：让每个 query 只能读它被分配到的那个读取集合，其余 token 全部屏蔽，然后照常往下算。打分仍然用 query 自己的 q\_i，模型权重一点都不变，只是限制了“能读谁”。

接着上面的例子：q1 被分给区域 A，只能读 token 2 和 3。原来 q1 对 4 个 token 的注意力权重是 (0.007, 0.002, 0.991, 0.0001)，只按说明书计算时变成 (0, 0.002, 0.998, 0)，几乎没变。对 q1 来说，这份说明书是够用的。

在真实的模型上，我们在几千张图片上统计“只按说明书计算时，预测类别和原来相同的比例”，称为**预测一致率**：

```latex
\text{Agree} = \frac{1}{N}\sum_{n=1}^{N} \mathbb{1}\big[\arg\max f(x_n) = \arg\max \tilde f(x_n)\big]
```

这里比较的是模型自己原来的预测，而不是真实标签，因为我们要解释的是模型本身。

检验可以有两种范围：所有层同时换成说明书，看整份说明书合起来够不够；每次只换一层，看哪一层的说明书最不够用。

这样，“解释是否忠实”就从看图判断，变成了一个可以直接测量的数字。有了这把尺子，我们就能回答三个问题。

## 六、我们发现了什么

**用这把尺子，我们依次回答三个问题：说明书够不够忠实，哪些层能被概括，说明书看到了什么。**【待填：三个问题各一句结论】

实验用的模型是 DeiT-S（在 ImageNet 上有监督训练）。前两个问题在 ImageNet 验证集随机抽取的 5,000 张图片上测；第三个问题用 Oxford-IIIT Pet 数据集，它标注了每张图里猫狗的位置。说明书固定分 16 块区域，改变每块区域读取的 token 数 k。

### RQ1：说明书够忠实吗？

我们把所有层同时换成说明书，看一致率如何随 k 变化（k 从 4 到 64）。

为了看清这个数字的意义，同时测两个参照。第一个是随机读取集合：每块区域随便选同样多的 token，它告诉我们“选对 token”比“随便选”多带来多少信息。第二个是按特征相似度分组（K-means，即 Clustered Attention 的分组方式），其余步骤不变，它告诉我们用人能读懂的图像区域来分组，忠实性表现如何。

结果：【待填：我们的方法比随机高多少；一致率达到 90% 时需要多大的 k；区域分组和 K-means 分组相差多少】。

### RQ2：哪些层能被概括？

这一次每次只把一层换成说明书，其余层保持原样，看换哪一层时预测变化最大。

MiTA 图 4 显示深层的读取集中在少数 token 上，所以深层可能更容易概括；但浅层以局部注意力为主，也可能很容易概括。实验直接告诉我们答案。

结果：【待填：哪些层容易概括、哪些层难】。

### RQ3：说明书看到了什么？

我们统计读取集合中落在猫狗身上的 token 所占的比例，即前景比例。如果随机选 token，期望值就是猫狗在图中所占的面积比例。猫狗通常在图片中央，所以还用一张“中间亮、四周暗”的中心图作为参照；再和最常用的 CLS 注意力热图比较。

结果：【待填：从第几层开始明显聚焦到物体上；比中心参照高多少；背景区域在读什么】。

这个问题直接呼应了我们最初被 MiTA 图 4 打动的现象：深层的注意力集中在物体上。不同的是，这次我们在一个普通的 ViT 里观察它，并且观察所用的说明书经过了执行检验。

## 七、局限与结论

**我们给 ViT 的注意力写了一份读得懂、而且可以检验的说明书。**

这项工作有三点局限。第一，经过多层注意力之后，深层的每个 token 都已经混入了其他位置的信息，所以读取集合说的是“这一层中被读取的 token 位置”，而不完全是原图上的位置。第二，核心实验只用了一个模型 DeiT-S。第三，我们用说明书的长度来衡量可读性，没有做用户调研。

回到最开始的问题：一张图在 ViT 里有约 280 万个注意力数值，没人读得懂，而现有的热图既丢失了结构，也无法检验。我们从 MiTA 得到两个启发：注意力是一个临时的 MLP，而且许多 query 共享同一小组神经元。基于这两点，我们把每一层概括成“m 块区域各读哪 k 个 token”的说明书，并通过“只按说明书计算”直接检验了它。

我们的贡献有三条：一个不需要训练、能读出注意力说明书的工具；一种把忠实性变成可测数字的检验方法；以及用它得到的发现：【待填，RQ1–RQ3 各一句】。

这把尺子也可以用到更多地方，比如比较有监督和自监督（DINO）模型的注意力，或者用来诊断一个模型是不是在“看背景作弊”。

## 问答准备

讲这个故事时最可能被问到的问题，每个用一两句话回答。更完整的解释见《研究设计书》第 8 节。

**“这和 MiTA 有什么不同？”** MiTA 是一种新的注意力结构，要拿来训练模型，目的是加速；我们不训练任何模型，只是借它的机制去读一个已经训练好的普通 ViT。

**“分组加 top-k 不是 Clustered Attention 早就有了吗？”** 机制确实来自那里，但他们用它加速，而且按特征相似度分组，分出来的组看不出是哪块区域。我们按图像区域分组，让它变成人能读的解释，并且用执行的方式检验它；RQ1 里也直接比较了这两种分组方式。

**“把注意力换掉了，测的还是原模型吗？”** 说明书是从原模型读出来的；执行只是检验它够不够用。如果只看说明书里的 token，模型给出的答案还和原来一样，说明说明书包含了模型需要的信息。

**“为什么比较预测一致，而不是准确率？”** 因为我们要解释的是模型本身，模型原来分错的图，说明书也应该让它同样地分错。

**“深层的 token 还代表原图的位置吗？”** 不完全代表，深层 token 混入了其他位置的信息，这是我们在局限里说明的一点，也是注意力可视化方法共有的问题。
