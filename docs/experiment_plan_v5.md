## 2. 定义

**符号。** 第 ℓ 层、第 h 个头；a(ℓ,h,i,j) 是 query i（全部 197 个 token，含 CLS）对 key j（196 个图块）的 softmax 注意力。

### 2.1 读取方式（代码 `src/mita_probe/readings.py`）

| 读法 | 第 ℓ 层的定义 | 修正哪个前提 |
| --- | --- | --- |
| R0 原始读取 | s_j = Σ_h Σ_i a_hij（即 S2 的 `attention_layer{l}`；单元测试检查两者相同） | — |
| C3 按贡献计分 | c_j = Σ_h Σ_i a_hij · ‖W_O^h v_hj‖₂（W_O^h 为 `attn.proj` 中第 h 个头的列，不计偏置） | M3 激活 ≠ 贡献 |
| C2 重新定位 | r_p = Σ_j s_j · P_ℓ(p \| x_j)；P_ℓ 是第 ℓ 层线性位置探针的 196 类 softmax | M2 token j ≠ 图块 j |
| C1 扣除与图片无关的成分 | s_j − s̄_j，s̄ 是同一种读取在留出图片上的平均图 | M1 与图片无关的成分 |
| R_all 合用 | 固定顺序 C3 → C2 → C1：先算 c，再重新定位，再减去“重新定位后的 c”的留出集平均图 | 三者 |
| R_all_alt 另一种顺序 | C3 → C1 → C2：先从 c 减去 c 的留出集平均图，再重新定位（附录 A7） | 三者 |

- **位置探针的输入**：第 ℓ 块 norm1 之后的 token，也就是产生第 ℓ 层 key 和 value 的表示。这与 E3 的 `identity.collect` 相同（已核对：`collect` 挂在 norm1 的输出上；`readings.capture` 取的是注意力模块的输入，就是 norm1 的输出）。
- **探针的训练**：与 E3 完全相同（标准化后的线性分类器，Adam，学习率 0.01，30 轮，种子 0），只是训练图片更多（见 B36）。
- **多层合并**：每层先算读法，再把各层相加。主结果用第 9–12 层（与 B22、S1 相同）。另外报告第 12 层单独的结果，以及第 1–4 层（只用于阴性对照 P4b）。
- **C1 与几何**：平均图按评估集的几何分别估计：ImageNet-S 用模型自己的 ImageNet 评估裁剪；ClickMe 用 ClickMe 的存储格式（见 B36）。

### 2.4 事先写明：哪些结果是构造上必然的（不算发现）

1. **三个指标都只看每张图内部的排序。** 所以给一张图的分数加常数或乘正数，结果不变。由此推出：值向量投影长度全部相等时，C3 与 R0 结果完全相同（单元测试）。
2. **C2 在恒等探针下返回 R0，并保持总量不变**（单元测试）。早期层探针接近恒等，所以 P4b 是实现检查，不是发现。
3. **与图片无关的参照（中心高斯、模型平均图）的图片特异 Spearman 和同距离富集接近 0。** 这是构造决定的。
4. **C1 与同距离富集。** 同一距离环内的排序只在平均图不是“同心圆”时才会改变。所以平均图越接近径向对称，C1 对这个指标的影响越小。运行中报告每张平均图被“距离环平均”解释的比例（`radial.csv`），解读时引用。扣中心高斯是严格径向对称的，它只能通过“前 \|物体\| 个图块在各环之间怎么分配”影响富集。
5. **C1 在留出集上平均为 0**（单元测试）；在评估集上不为 0。
6. **C2 与删除式忠实度（SRG）。** SRG 在输入层删除图块；C2 把深层分数画到 token 现在代表的位置。两者说的是同一个“位置”，但 C2 的位置来自探针，不是来自模型的计算。所以 C2 改变 SRG，说明的是“探针认为的位置”是否更接近模型依赖的输入图块。

## 5. 预测、判定标准与事先约定的解读（B38）

**统计（B10）**：先按图片求值（随机对照先按种子 0–4 平均），再按图片配对 bootstrap（1,000 次，种子 0），取 95% 百分位区间。

**判定界限（B22）**：SRG 0.05；同距离富集 0.02；ClickMe 图片特异 Spearman 0.02。
- “相当”：差的 95% 区间含 0，或差的绝对值小于界限。
- “更高 / 更低”：区间全在 0 以上 / 以下，且绝对值不小于界限。

**P3 的三种事先约定解读：**

1. **成立（4/4）**：视角推出的修正能改进读法。论文 5.3 节写改进幅度，并逐个说明哪种修正有贡献。只有在“修正 − 对照”也“更高”时，才说这种修正的作用超出了它的对照（例如 C2 超出同等模糊）。
2. **部分成立（1–3/4）**：修正只在部分模型或指标上有效。论文写清楚在哪里有效、在哪里无效，不概括为“修正有效”。
3. **不成立（0/4）**：三个前提的失效是真实的（第 2 步），但只改读法不能把它们修回来。论文结论写成“视角能诊断误读，但读法修正的作用有限”；再与扩展 E（改模型也只是挪动预算）并列，说明两条路都有限。

**其他事先说明：**
- **复现检查**：新运行的 R0 与 S1/S2 的完整注意力在同一批图片上，三个指标的均值差都应小于 0.01（B22 (7) 的写法）。不满足时如实报告，不停止。
- **健全性检验**（v3 B14 的流程和门槛）：全部块随机化后，Spearman 中位数 < 0.5 记为“通过”。预测：R0、C1、C2、C3、R_all 都通过；中心参照作为“不通过”的样子。平均图和位置探针始终来自训练好的模型，不在每一级重新估计。
- **修正顺序（A7）**：R_all_alt − R0 与 R_all − R0 的判定（更高 / 相当 / 更低）在所有格中都相同，记为“稳健”。只描述。
- **扩展 A–E**：保持原判定，包括不成立的部分（MiTA Tiny、DeiT-B 的 register 门槛），不为故事重新解释。
