# 研究设计：ViT 的注意力去了哪里？

Nov 2, 2026 · @deng

**一句话：** ViT 的注意力在每一层都必须把一笔“预算”（加起来等于 1）全部花出去。本研究先弄清这笔预算花在哪里、有没有被用上，再检验两个杠杆能否把它引向物体。

**暂定题目：** *Where Does ViT Attention Go, and Can We Redirect It? Fast- and Slow-Weight Levers on the Attention Budget*

## 1. 研究背景与问题的提出

### 1.1 注意力图被当作"模型在看哪里"的证据

解释 Vision Transformer（ViT）时，最常见的做法是画出注意力图，看注意力落在哪些图块上。近来有两类工作进一步声称：对模型做某种改动，能让注意力更干净、更集中在物体上。

- **稀疏化注意力。** [MiTA](https://arxiv.org/html/2602.01219)（2026）让每个 query 只读少数 top-k 个 token。论文图 4 显示，深层大多数 token 被"剪掉"，剩下的集中在与类别相关的区域。
- **处理注意力 sink。** 有监督和自监督 ViT 中都有少数"高范数 token"，大量注意力集中在它们身上（Darcet 等 2024）。[Jiang 等 2025](https://arxiv.org/abs/2506.08010) 在 OpenCLIP 和 DINOv2 中找到制造这些 token 的少数 FFN 神经元，测试时把它们的激活移到一个额外的 token 上，注意力图随之变干净。[Fesser 等 2026](https://arxiv.org/abs/2606.08105) 进一步把 sink 分成"空操作型"和"广播型"，并发现加 register 只是挪动了 sink 的计算，而没有消除它。

### 1.2 这类结论有两个共同的漏洞

1. **中心偏差。** 物体通常在画面中间，任何偏向中间的注意力都会"看起来"聚焦物体（Zhang 等 2016；Choe 等 2020；Fel 等 2022）。MiTA 图 4 只用了几张训练集图片，没有定量指标，没有和普通注意力模型对比，也没有扣除中心偏差。
2. **看起来干净，不等于注意力流向了物体。** softmax 让每个 query 的注意力加起来必须等于 1。高范数 token 被移走后，腾出来的注意力可能流向物体，也可能流向别处，例如新加入的额外 token。

**举例：** 有监督的 DeiT-B 第 11 层，约 3% 的 token（高范数 token）拿走了约 61% 的注意力。把这些 token 去掉之后，注意力图看起来会干净得多；但如果腾出的 61% 主要流向一个额外 token，而物体分到的比例几乎没变，那么"更干净"并不意味着"更关注物体"。

### 1.3 前期证据

本项目已有的结果提示，上面两个漏洞是真实存在的：

- 在 Pet 数据集上，MiTA-DeiT-S 第 11 层读取的 token 中 51.0% 在物体上，而物体本来就占画面 51.2%；普通 DeiT-S 是 65.4%，自监督的 DINO 是 85.1%。
- 把高范数 token 从模型的读取范围中拿掉，DeiT-S 的预测几乎不变；拿掉物体 token，预测明显变差。也就是说，高范数 token 上的大量注意力可能并没有被用上。
- 有监督模型的最后一层，注意力会离开物体；DINO 不明显。原因还不清楚。

### 1.4 研究空白

还没有工作在**配对模型**上、**扣除中心偏差**后，定量检验"稀疏化注意力"或"移走制造 sink 的神经元"能否把 ViT 的注意力引向物体；有监督 ViT 中是否存在制造 sink 的 FFN 神经元，也尚未检验。

"注意力必须分完，因而会出现 sink"这一观察本身并不新（StreamingLLM，Xiao 等 2024；Darcet 等 2024）。本研究把它用作组织问题的框架，贡献在于对两个杠杆的定量检验。

## 2. 研究问题与假设

**主问题：ViT 的注意力预算花在哪里？哪些杠杆能把它引向物体？**

主问题拆成三个依次递进的研究问题：先建立一本"预算账"，再分别检验两个杠杆能否改写它。

| 研究问题 | 要回答什么 |
| --- | --- |
| **RQ1 去向** | 注意力预算逐层花在物体、背景、高范数 token、CLS 上各多少？扣除中心偏差后，不同训练方式给物体的预算有何不同？花在高范数 token 上的预算有没有被用上？ |
| **RQ2 杠杆 A** | 训练时稀疏化注意力（top-k），能否把预算引向物体？ |
| **RQ3 杠杆 B** | 测试时移走制造高范数 token 的 FFN 神经元，腾出的预算会流向物体吗？ |

### 验证性假设

以下假设在任何新实验之前登记，方向依据前期证据和已有文献。

| 编号 | 对应 | 假设 | 依据 |
| --- | --- | --- | --- |
| H1 | RQ1 | 自监督的 DINO 比所有有监督模型都明显更聚焦物体 | 前期 DINO 结果 |
| H2 | RQ2 | 在两组配对模型中，top-k 训练都没有让预算明显更偏向物体 | 前期 Pet 结果；Meister 等 2021（稀疏注意力不一定更可解释） |
| H6 | RQ3 | 移走制造高范数 token 的神经元，不会让预算明显更偏向物体 | Fesser 等 2026：register 只是挪动 sink |

RQ3 另有两个前提，它们不是要检验的结论：

- **关卡（H3）：** 有监督 ViT 中能否找到制造高范数 token 的神经元。找不到时，RQ3 改为描述性分析。
- **操作检查（H4）：** 移走这些神经元后，高范数 token 是否真的消失、模型准确率是否基本不变。这一步确认干预确实起了作用，腾出的预算流向哪里只作描述。

编号沿用项目登记时的顺序；原来的 H5 已并入 H4。

### "明显"如何判断

事先定一个"值得在意的最小差"：**同环物体富集（第 3 节）相差不到 0.03，视为没有明显差别。** 它约为 DeiT-S 深层富集（约 0.10）的 30%。

这样做是为了避免把"没找到差别"当成"没有差别"。例如只有 20 张图时，区间可能是 −0.3 到 +0.3，包含 0，但这什么也没证明。只有当区间完全落在 0.03 以下，才能说"没有明显提高"。

## 3. 理论框架与总体设计

### 3.1 一个 block，两个 MLP

一个 ViT block 包含两个结构相同的两层网络：

- **注意力是快权重 MLP。** 每个 token 是一个隐藏神经元；它的权重（key、value）随每张图片变化。一个 query 对各 token 的注意力权重，就是这个 query 的预算如何分配。
- **FFN 是慢权重 MLP。** 隐藏单元训练后固定不变。其中少数神经元可能制造高范数 token，而高范数 token 正是吸走预算的地方。

### 3.2 两个杠杆，一个参照

这个框架让两种"让注意力聚焦物体"的做法可以放在一起比较：它们分别作用在两种 MLP 上，但问的是同一件事——**能否把预算引向物体**。

|  | 作用在哪里 | 怎么操纵 | 怎样得出因果结论 |
| --- | --- | --- | --- |
| 杠杆 A | 快权重（注意力） | 训练时只让每个 query 读 top-k 个 token（MiTA） | 比较"只差 top-k"的配对模型 |
| 杠杆 B | 慢权重（FFN） | 测试时把制造高范数 token 的神经元的激活移到一个额外 token 上 | 同一个模型、同一张图，只改动这些神经元，并设对照 |
| 参照 | 训练目标 | 不操纵，只比较自监督的 DINO | 不作因果结论，只说明另一种训练目标下的样子 |

&#91;embedded content: 设计逻辑 · 两个杠杆、一个参照\]

杠杆 B 作用在上游的慢权重（制造高范数 token 的 FFN 神经元），杠杆 A 作用在快权重本身（注意力如何分配预算）；两者都以“物体分到的预算是否变多”为结果。

### 3.3 研究对象

| 模型 | 代表什么 | 用在哪里 |
| --- | --- | --- |
| DeiT-S 与 MiTA-DeiT-S | 训练方法相同、只差 top-k 的一对（Small 规模） | RQ1、RQ2 |
| DeiT-T 与 MiTA-DeiT-T | 同样的一对（Tiny 规模），检验效应能否重复 | RQ1、RQ2 |
| DeiT-III-S | 另一种有监督训练配方 | RQ2 中衡量"普通训练差异有多大" |
| DeiT-B | 高范数 token 最明显的有监督模型 | RQ1、RQ3 主模型（DeiT-S 为辅） |
| DINO ViT-S | 自监督、没有高范数 token | RQ1 参照；RQ3 搜索神经元时的阴性对照 |

数据以带像素级物体掩码的 ImageNet-S 验证集为主，用来判断每个图块是物体还是背景；另用 ImageNet 验证集测量模型准确率。

### 3.4 三个核心测量

| 测量 | 回答什么 | 简要说明 |
| --- | --- | --- |
| 预算份额 | 预算花在哪里 | 每层、每个 head，注意力落在物体、背景、高范数 token、CLS 上的比例 |
| 同环物体富集 | 是否真的偏向物体 | 只在离图像中心距离相同的图块之间比较，从而扣除中心偏差；只看偏向中间的读取得分为 0 |
| 用没用上 | 花出去的预算是否被模型使用 | 拿掉某类 token 的读取后，模型对原答案的把握下降多少，并与"拿掉同样多预算的普通 token"比较 |

## 4. 研究阶段

研究分为五个阶段。阶段一保证测量可信、比较公平；阶段二到四分别回答 RQ1 到 RQ3；阶段五把结果合在一起回答主问题。每个阶段都按"目的、做法、证据与判断、结果的解读、与后续的关系"来写。

&#91;embedded content: 研究阶段 · 五个阶段与一个关卡\]

阶段三和阶段四都以阶段二的预算账为基准，彼此独立；阶段四能否做因果干预，取决于阶段一的关卡。

### 阶段一：准备与测量的验证

**目的：** 在看到任何新结果之前，固定研究假设；确认要比较的模型可靠、可比；确认测量足够精确；判断 RQ3 能否做因果检验。

**做法：**

1. **先登记，后实验。** 把 H1、H2、H6 和最小差 0.03 写下来，并说明已经看过哪些前期结果。之后的任何实验结果都不能用来修改它们。
2. **确认模型可用、可比。** 加入 DeiT-T、MiTA-DeiT-T 和 DeiT-III-S，确认它们能复现公开报告的准确率。逐图配对比较要求所有模型对同一张图的图块划分完全相同，所以统一使用同一种图像预处理，并检查这样做是否明显改变某个模型的准确率。
3. **估计测量精度。** 在一小批**不参与正式评估**的图片上试算，估计结果的波动有多大、需要多少张图才能让判断足够明确。用另一批图片，是为了避免提前看到正式结果。
4. **检查 RQ3 的可行性。** 在有监督 ViT（DeiT-B、DeiT-S）中寻找制造高范数 token 的 FFN 神经元：看哪些神经元恰好在"即将变成高范数 token"的位置上激活特别大。DINO 没有高范数 token，作为阴性对照，预期找不到。

**产出：** 一份可比较的模型名单；对测量精度的估计；"能否找到制造高范数 token 的神经元"的结论。

**结果如何影响后续：**

- 若 MiTA-DeiT-T 拿不到或复现不了，RQ2 只用 Small 规模的一组配对，并在局限中说明。
- 若找到了这些神经元，阶段四做因果干预；若找不到，阶段四改为描述性分析。

### 阶段二：建立注意力预算账（RQ1）

**目的：** 在不做任何干预的情况下，弄清每个模型的注意力预算逐层花在哪里，以及花在高范数 token 上的那部分有没有被用上。这本账是后面检验两个杠杆的基准。

**研究对象：** 第 3.3 节的全部七个模型。

**做法：**

1. **逐层记账。** 对每一层，统计注意力落在物体、背景、高范数 token、CLS 上的比例。MiTA 的每个 query 除了读少数 token，还会读几个"压缩槽"；压缩槽的值本身是对全部 token 的加权和，所以按它对各 token 的注意力权重，把落在槽上的预算分回到 token 上，不能直接丢掉。
2. **测量物体聚焦，并排除高范数 token 的干扰。** 用同环物体富集衡量物体聚焦。这个指标按排名挑出收到注意力最多的图块再计算，而高范数 token 收到的注意力极多、又大多在背景上，会挤占排名。所以主结果只在"不是高范数 token 的图块"上计算；包含全部图块的结果作为对照，两者之差说明"看起来的聚焦"有多少是被高范数 token 左右的。
3. **判断高范数 token 上的预算是否被用上。** 在所有出现高范数 token 的层上，同时拿掉模型对它们的读取，看模型对原答案的把握下降多少；对照组是拿掉**收到同样多注意力**的普通 token。用随机 token 作对照不公平，因为随机 token 本来就分不到多少注意力。
4. **判断高范数 token 属于哪一类 sink。** 对同一批高范数 token 做三种处理：把它们写回的内容置零；换成数据集上的平均值；不让任何 query 读取它们。三种处理的效果差异，加上 Fesser 等 2026 的两个诊断（value 的长度、输出的秩），一致时才下结论：
   - **空操作型：** 写回的内容接近 0，head 把注意力放在这里只是为了"不干活"。
   - **常数偏置型：** 写回的内容很大但每张图都差不多，相当于一个常数项。
   - **广播型：** 写回的是每张图特有的全局信息。
5. **追踪最后一层的去向。** 有监督模型在最后一层离开物体，记录离开的预算转去了哪里。

**证据与判断：** H1 用 DINO 与每个有监督模型的物体聚焦之差来检验：每个差值的区间下限都超过 0.03，才判定"DINO 明显更聚焦"。其余内容是描述性的，只报告估计和区间。

**结果的解读：**

- 若高范数 token 上的预算没被用上（空操作型或常数偏置型），说明注意力图会把"被读了"误当成"被用了"。
- 若被用上了（广播型），说明高范数 token 是汇集和分发全局信息的枢纽，读取它们是有用的。

**与后续的关系：** 阶段三、四都与这本账对照；对高范数 token 的定性，也说明了阶段四的干预究竟移走的是什么。

### 阶段三：检验杠杆 A——top-k 训练（RQ2）

**目的：** 检验"训练时稀疏化注意力，会让 ViT 的注意力更集中在物体上"这一说法。

**研究对象：** 两组只差 top-k 的配对模型——DeiT-S 对 MiTA-DeiT-S，DeiT-T 对 MiTA-DeiT-T；另用 DeiT-III-S 作参照。

**做法：**

1. **配对比较物体聚焦。** 对同一张图，比较每组配对中两个模型深层（第 9–12 层）的同环物体富集。只在"两个模型都不是高范数 token"的图块上比较，避免"谁的高范数 token 多"影响结果。
   - 例子：一张图中 DeiT 有 5 个高范数 token，MiTA 有 3 个，位置部分重叠，合计 7 个；两个模型都在剩下的图块上比较。
2. **比较预算的分配。** 两个模型分别把多少预算花在物体、背景、高范数 token 上；MiTA 花在压缩槽上的预算，按阶段二的方法分回 token。
3. **复核 MiTA 图 4。** 按 MiTA 图 4 的画法（每层被选中的 token 的并集）重新画一遍，并计算其中有多少"聚焦"可以由中心偏差解释，说明那张图的印象从何而来。

**对照：** DeiT-III-S 与 DeiT-S 之间的差别，代表"换一种训练方式本身"会带来多大的差别。如果 MiTA 与 DeiT 的差别比这还小，就不能归功于 top-k。

**证据与判断（H2）：**

| 结果 | 判定 |
| --- | --- |
| 两组配对的差值区间都完全低于 0.03 | 成立：两组配对中都没有看到明显提高 |
| 任一组的差值区间完全高于 0.03 | 不成立：top-k 明显提高了物体聚焦 |
| 其他情况 | 不确定 |

**结果的解读：**

- 若成立，MiTA 图 4 的"聚焦"主要来自中心偏差和可视化方式，而不是 top-k 本身。
- 若不成立，top-k 确实把预算引向了物体，需要进一步解释原因。
- 若两组配对方向不一致，效应可能依赖模型规模，结论只能限定在单一规模。

**措辞的限制：** 每个模型只训练过一次，区间只反映图片之间的波动，不反映"重新训练一次"的波动。所以即使 H2 成立，也只能说"两组配对中都没有看到明显提高"，不能推广为"top-k 不会提高"。

### 阶段四：检验杠杆 B——移走制造高范数 token 的神经元（RQ3）

**目的：** 检验"去掉高范数 token，注意力就会转向物体"这一说法；同时检验 Jiang 等 2025 在 CLIP、DINOv2 上的发现能否推广到有监督 ViT。

**研究对象：** DeiT-B 为主，DeiT-S 为辅。MiTA 不做这项干预，因为它的实现方式与插入额外 token 不兼容。

**做法：**

1. **确定要移走的神经元。** 使用阶段一找到的、制造高范数 token 的 FFN 神经元。
2. **干预。** 测试时在 CLS 之后加入一个额外 token，把这些神经元在所有图块上的激活移到这个额外 token 上（Jiang 等 2025 的做法）。模型不重新训练。
3. **设置对照，排除其他解释：**

| 对照条件 | 排除的解释 |
| --- | --- |
| 只加额外 token，不改动神经元 | 多出一个可读的 token 本身就会吸走注意力 |
| 移走同样数量的随机神经元 | 任何改动都会有效果 |
| 移走同样数量、激活同样大的其他神经元 | 只要动了激活很大的神经元就会有效果 |
| 直接把这些神经元置零（不加 token） | 区分"移走"与"删除"对模型的影响 |

4. **观察四件事：**
   - 高范数 token 是否消失、模型准确率是否基本不变（操作检查 H4）；
   - 腾出的预算流向哪里：物体、背景、额外 token 还是 CLS（描述）；
   - 物体聚焦是否提高（H6）；
   - 最后一层离开物体的现象是否消失（描述）。

**证据与判断（H6）：** 比较干预前后的同环物体富集；两次计算都排除干预前的高范数位置，否则高范数 token 一消失，排名就会机械变化，富集会"自动"上升。

- 例子：一张图有 60 个物体图块，前 60 名里有 6 个是背景上的高范数 token。这 6 个消失后，第 61–66 名补上来，其中约一半是物体，富集就会上升约 0.05——但预算其实没有流向物体，只是排名变了。

判定方式与 H2 相同：区间完全低于 0.03 为"没有明显提高"，完全高于 0.03 为"明显提高"，其他为不确定。

**结果的解读：**

- 若腾出的预算主要流向额外 token、物体聚焦不变：高范数 token 只是预算的"停靠点"，与 Fesser 等 2026 一致；去掉它们并不会让模型更关注物体。
- 若预算回到物体、聚焦明显提高：高范数 token 挤占了本该给物体的预算。
- 若最后一层的漂移消失：漂移由高范数 token 造成；若仍在：另有原因。

**若阶段一没有找到这些神经元：** 这本身是一个发现——Jiang 等的结论不能直接推广到有监督 ViT。此时 RQ3 改为描述：高范数 token 在哪些层出现、出现在什么位置、它们上面的预算有没有被用上（阶段二已经回答）。

### 阶段五：综合与结论

**目的：** 把预算账、两个杠杆的检验和 DINO 参照放在一起，回答主问题：注意力预算花在哪里，哪些因素能把它引向物体。

**做法：**

1. **把三方面的证据并列。** 对每个模型，并列它的预算去向（阶段二）、杠杆 A 的效果（阶段三）、杠杆 B 的效果（阶段四），以及与 DINO 的差别。
2. **回答主问题。** 若两个杠杆都没有明显提高物体聚焦，而 DINO 明显更聚焦（H1），结论是：在本研究检验的范围内，决定注意力是否聚焦物体的，是训练目标，而不是注意力是否稀疏、也不是是否存在高范数 token。若某个杠杆有效，结论相应修改。
3. **决定论文讲哪个故事。** 这个标准在看到正式结果之前写定：
   - **以本研究为主线**，如果 H2 有明确判定（不是"不确定"）且两组配对方向一致，并且以下至少一条成立：RQ3 完成了因果干预，或阶段二能明确判断高范数 token 上的预算是否被用上。
   - **否则以项目现有论文为主线**，修正其中的旧证据，把 RQ1、RQ2 的结果作为新的一节加入。
4. **修正现有论文中的一处旧证据。** 现有论文用"只把一层注意力换成读取名单，仍保留 92%–96% 的预测"来证明读取名单就是模型在用的东西。但整层注意力直接删掉也保留 92.9%–97.3%，这条证据区分不了"名单是对的"和"这一层本来就不重要"。无论选哪个故事，都改为用 12 层同时替换的结果，并给出"12 层注意力全部删掉"的对照。

**产出：** 对主问题的回答；论文的主线；一组经过修正、可以直接写进论文的结论。

## 5. 分析与判断原则

以下原则适用于所有阶段，是结论能否成立的前提。

1. **以图片为单位，逐图配对。** 同一张图在不同模型、不同条件下比较，差值再在图片之间汇总，并给出区间。
2. **用最小差判断"明显"。** 有差别要超过 0.03，没差别要整个区间低于 0.03；其他情况如实写"不确定"。
3. **扣除中心偏差。** 物体聚焦一律用同环物体富集衡量。
4. **排除高范数 token 后再比较。** 每组比较只在两边都不是高范数 token 的图块上进行；包含全部图块的结果作为次要结果。
5. **对照要公平。** 判断"用没用上"时，对照是收到同样多注意力的普通 token；判断杠杆 B 时，对照包括"只加 token""随机神经元""激活同样大的神经元"。
6. **只有三个验证性假设。** H1、H2、H6 作判定，并报告多重比较校正后的结果；其他结果只描述，不作判定。
7. **先登记，后看结果。** 假设和判定标准在正式实验前写定；看到结果后新增的分析，明确标为"事后分析"。
8. **单层的一致率不能作为"被使用"的证据**，必须同时给出"整层删掉"的对照。

## 6. 效度与局限

设计中的对照针对最容易把结论带偏的几个因素；仍然存在的局限在论文中如实说明。

| 风险 | 例子 | 本研究的处理 |
| --- | --- | --- |
| 中心偏差 | 物体多在中间，偏向中间的读取都像"聚焦物体" | 同环物体富集 |
| 高范数 token 造成的排名变化 | 高范数 token 一消失，富集就"自动"上升 | 排除高范数位置后再比较 |
| 每个模型只训练一次 | MiTA 与 DeiT 的差别可能只是偶然 | 两组配对；DeiT-III-S 衡量普通训练差异；结论措辞受限 |
| 配对并非完全同源 | DeiT 由官方训练，MiTA 由其作者用自己的代码训练 | 在局限中说明 |
| 额外 token 本身的影响 | 多一个可读的 token，就可能吸走注意力 | "只加 token"对照 |
| 注意力多不等于重要 | head 没事可做时，也必须把注意力放在某处 | 区分"被读了"和"被用了" |
| 深层 token 不再代表原来的位置 | 第 12 层的 token 只有 15%–25% 能被认出原来的图块 | 深层的"去向"只解读为"去了哪些 token 位置"；以第 9–12 层平均为主 |
| 范围有限 | 只有 Tiny、Small、Base 三个规模；稀疏注意力只检验了 MiTA 一种；只用 ImageNet 类数据 | 结论限定在所检验的模型和数据上 |

## 7. 预期结果与贡献

根据前期证据，最可能的整体结论是：**两个杠杆都不能把有监督 ViT 的注意力明显引向物体，真正不同的是训练目标。** 但每个研究问题的两种结果都能写成完整的论文。

| 研究问题 | 若如预期 | 若相反 |
| --- | --- | --- |
| RQ1 | 高范数 token 上的预算没被用上：注意力图会把"被读了"误当成"被用了" | 这些预算被用上了：高范数 token 是汇集全局信息的枢纽 |
| RQ2 | MiTA 图 4 的"聚焦"主要来自中心偏差和画法 | top-k 确实把预算引向物体，需要解释原因 |
| RQ3 | 腾出的预算流向额外 token，物体聚焦不变 | 预算回到物体：高范数 token 挤占了物体的预算 |
| RQ3 前提 | 找到制造高范数 token 的神经元，可做因果干预 | 找不到：Jiang 等的结论不推广到有监督 ViT，本身是发现 |

**预期贡献：**

1. 一本扣除中心偏差的注意力预算账，并区分高范数 token 上的预算是否被用上、属于哪一类 sink。
2. 第一次用配对模型定量检验"top-k 训练让 ViT 聚焦物体"这一说法。
3. 第一次在有监督 ViT 上检验"移走制造 sink 的神经元"能否改变注意力的去向。

**对可解释性的意义：** 如果结论如预期，那么"注意力图看起来更干净、更聚焦"——无论来自稀疏注意力还是来自 register——都不能直接当作模型更关注物体的证据；解读注意力图时，必须扣除中心偏差，并区分"被读了"和"被用了"。
