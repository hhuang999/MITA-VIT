### 1.2 它能补上现有论文的哪些弱点

1. **单层执行的证据区分力不足。** 论文第 30、104 行用"只替换一层，保留 92%–96% 的预测"来说明读取名单是真的。但项目自己的记录（`docs/analysis/v2_anatomy.md`）显示：**把一层注意力整个删掉，也保留 92.9%–97.3%**（第 1 层除外）。所以单层的数字区分不了"名单对"和"这一层本来就不重要"。论文里其实已经有更强的证据：12 层同时替换保留 72%，随机名单只有 9%。修正很便宜，只需改写措辞，再加一行"12 层注意力全部删掉"的对照（T7）。**这条修正不管新研究做不做都应该做。**
2. **高范数 token 上的注意力有没有被用上，还没有回答。** S3 发现，DeiT-B 第 11 层 3.1% 的图块收到 43.5% 的完整注意力（探针读取是 61%）。以前唯一的检验（B3，Pet，探针名单内删除后按排名补满）没有看到预测下降。但那个检验每删一个就补一个，并不等于"不读它们"。这次直接检验。
3. **最后一层离开物体的原因不清楚。** S3 的预测（"是高范数 token 造成的"）在 DeiT-S 上不成立。阶段二第 5 步和阶段四正好检验这个问题。

## 2. 需要用户确认的修改

下面几处与研究设计的原则或流程不同。按研究设计第 8 节，这些必须先问你。

### M1. "用没用上"的对照：改成两种"数量相同"的对照（与原则 5 冲突）

研究设计要求对照组是"收到同样多注意力的普通 token"。这在关键的层上**做不到，或者会把结论带偏**。

**举例：** DeiT-B 第 11 层，6 个高范数图块收到 43.5% 的注意力。要让普通图块凑够 43.5%，就得拿掉几十个收到注意力最多的普通图块，而这些图块大多在物体上。这样对照组拿掉的信息多得多，预测必然下降更多，"高范数 token 没被用上"就几乎一定会成立。这个结论是对照的设计造成的，不是模型告诉我们的。

**建议：**
- **主对照 C1：** 拿掉同样数量的"收到注意力最多的普通图块"。这是最严格的普通对照，单个 token 能比的最高水平。
- **主对照 C2：** 拿掉同样数量、在相同距离环上随机选的普通图块（种子 0–4），沿用 `interventions.replace_matched_patches` 的思路。
- **次要结果：** 只在能做到的层上做"同样多注意力"对照，并报告每种做法实际拿掉了多少注意力。
- **判断：** 高范数 token 造成的下降，比 C1 和 C2 都明显小（差值区间整个在 0 以下），才说"没被用上"；比两者都大，才说"被用上了"；其他情况写"不确定"。

### M2. 预算按完整注意力计算，并更正例子

预算就是每个 query 的 softmax 权重（每行加起来等于 1）。MiTA 落在压缩槽上的部分，按槽对各 token 的权重分回去（见 3.4）。研究设计 1.2 节例子中的 61% 改为 43.5%，并注明 61% 是探针读取的数字。

### 3.4 核心测量的定义

**注意力矩阵。** 对第 l 层第 h 个 head，A[q, j] 是 query q 分给 token j 的权重，每行加起来等于 1。

- 普通 ViT：直接取 softmax。
- MiTA：A = P_token + P_slot · S。其中 P_token 是 query 分给被选中 token 的权重，P_slot 是分给压缩槽的权重，S[s, j] = softmax(landmark_s · key_j) 是槽 s 对 token j 的权重。因为 S 的每行加起来等于 1，A 的每行仍然等于 1，而且 A·V 与 MiTA 的实际输出相同（有单元测试）。

**图块类别**（每层、每张图各算一次；一个图块只属于一类，按顺序判定）：
1. CLS
2. （阶段四）额外 token
3. 高范数：该层块输入的长度超过本图图块中位数的 3 倍（沿用 B24 和 `interventions.sink_tokens`）
4. 物体
5. 背景
6. 未知

**预算份额。** 某层落在某类上的预算 = 所有 query、所有 head 分给该类 token 的权重的平均值。主结果包含全部 query；只看 CLS query 的结果另外报告。

**同环物体富集。**
- 先算每个图块在第 9–12 层收到的注意力之和（即 S1 的 `attention_mass`），再用 `plausibility.measures` 计算同环物体富集（0 = 和中心先验一样）。
- 主结果把高范数位置从候选图块中去掉（把它们标成无效）。要去掉的位置是：
  - 单个模型：第 9–12 层高范数位置的并集
  - 配对比较：两个模型各自并集的并集
  - 阶段四：干预前的并集
- 包含全部图块的结果作为次要结果。
- 逐层曲线用同样的方法逐层计算。

**"用没用上"。** 在出现高范数图块的所有层上，同时让所有 query 不再读取这些图块（把它们在注意力打分中设为负无穷，再重新做 softmax）。然后测两件事：
- 模型对原来 top-1 类别的 log 概率下降多少；
- top-1 与原模型一致的比例。

对照组 C1、C2 的设计见 M1。

**sink 分型的三种处理。** 对同一批高范数图块（只在它们是高范数的层上处理）：

| 处理 | 做法 | 含义 |
| --- | --- | --- |
| 置零 | 把它们的 value 设为 0，注意力权重不变 | 预算照样花，但不带回内容 |
| 平均值替换 | 把 value 换成预试验集 P 上同层、同 head 高范数图块 value 的平均值 | 只保留"常数项" |
| 不读 | 同"用没用上" | 预算重新分给其他 token |

另外按 Fesser 等 2026 计算两个诊断：
- value 长度比：高范数图块 value 的长度 ÷ 普通图块 value 长度的中位数；
- 输出有效秩：该 head 输出矩阵的熵有效秩。只在预算被高范数图块拿走一半以上的 head 上计算。

分型规则（数值门槛在预试验后、正式运行前登记）：

| 类型 | 条件 |
| --- | --- |
| 空操作型 | 置零后几乎没有影响，而且 value 长度比小 |
| 常数偏置型 | 置零有影响，但平均值替换几乎没有影响 |
| 广播型 | 平均值替换也有影响，而且输出有效秩低 |
| 不确定 | 证据不一致 |

### 3.5 制造高范数 token 的神经元（阶段一第 4 步、阶段四）

**搜索**（在预试验集 P 上，模仿 Jiang 等 2025 的算法 1）：
1. 找出高范数图块开始大量出现的层 L*：第一个有至少 50% 的图片出现高范数图块的层。
2. 在 L* 之前各层的 FFN 隐藏单元（`mlp.act` 的输出）上，给每个神经元打分：它在"将在 L* 变成高范数"的位置上的平均激活，减去在其他图块上的平均激活，再除以标准差。
3. 按分数从高到低，依次取前 n 个神经元，n ∈ {1, 2, 4, 8, 16, 32}。

**关卡 H3（在 P 上判定，正式运行前登记）：** 存在一个 n ≤ 32，使得下面三条同时成立，就算"找到了"，并取满足条件的最小 n：
- 把这 n 个神经元移到额外 token 后，第 L* 层及之后的高范数图块减少至少 80%；
- top-1 与原模型的一致率至少 95%；
- 移走同样数量的随机神经元（种子 0–4），高范数图块最多减少 20%。

DINO 也跑一遍，作为阴性对照（预期没有高范数图块，也找不到神经元）。

**干预（测试时加额外 token）：**
- 在 CLS 之后插入一个全零的额外 token，不加位置编码。
- 在神经元所在的层，把这些神经元在所有图块上的激活清零，同时把图块中最大的激活值写给额外 token（Jiang 等的做法）。
- 模型不重新训练。

**条件（都在正式集 F 和 ImageNet 验证集上跑）：**

| 编号 | 条件 | 排除的解释 |
| --- | --- | --- |
| R0 | 原模型 | 基准 |
| R1 | 只加额外 token，不动神经元 | 多出一个可读的 token 本身就会吸走注意力 |
| R2 | 移走找到的神经元（主干预） | — |
| R3 | 移走同样数量的随机神经元（种子 0–4） | 任何改动都会有效果 |
| R4 | 移走同样数量、平均激活最接近的其他神经元 | 只要动了激活大的神经元就会有效果 |
| R5 | 把找到的神经元直接置零，不加 token | 区分"移走"和"删除" |

**操作检查 H4（判定门槛先登记）：** R2 使高范数图块减少至少 80%；ImageNet 准确率下降不超过 1 个百分点。不通过时，R2 的结果只作描述，H6 记为"无法检验"。

### 3.6 复核 MiTA 图 4（阶段三第 3 步）

按 MiTA 图 4 的画法，取每层所有 query 选中 token 的并集，得到一张 0/1 图。然后计算两个量：
- 这张图上的物体比例；
- 同环物体富集（扣除中心偏差之后还剩多少）。

两个 MiTA 模型都算，并与对应 DeiT 的同等画法比较（DeiT 取每个 query 的 top-25）。

### 3.7 执行证据的修正（阶段五第 4 步）

在 ImageNet 验证集的固定 5,000 张图（与论文图 2c 相同）上，对 DeiT-S、DINO、DeiT-B 三个模型各测一次：12 层注意力全部删掉（每个 block 的注意力分支输出设为 0，只留残差和 FFN）后的 top-1 一致率。论文执行证据一节改为以"12 层同时替换 72%、随机名单 9%、全部删掉 x%"为主；单层的数字只用来回答"哪一层相对难替换"。

## 5. 统计与判定

- **单位：** 以图片为单位逐图配对；差值在图片间汇总。
- **区间：** 配对 bootstrap，种子 0。描述性结果用 1,000 次重抽样的 95% 区间（与项目现有做法相同）。
- **多重比较：** 判定用的比较共 10 个，统一用 Bonferroni 校正后的 99.5% 区间。99.5% 区间需要更多次重抽样才稳定，所以判定区间用 10,000 次重抽样。这 10 个比较是：
  - H1：DINO 对 6 个有监督模型
  - H2：两组配对
  - H6：DeiT-B、DeiT-S
- **最小差 0.03**（研究设计已定）：

| 假设 | 成立 | 不成立 | 其他情况 |
| --- | --- | --- | --- |
| H1 | 6 个差值（DINO − 有监督）的区间下限都高于 0.03 | 任一差值的区间上限低于 0.03 | 不确定 |
| H2 | 两组（MiTA − DeiT）的区间上限都低于 0.03 | 任一组的区间下限高于 0.03 | 不确定 |
| H6 | 两个模型的（R2 − R0）区间上限都低于 0.03 | 任一模型的区间下限高于 0.03 | 不确定 |

- **H2 的参照：** DeiT-III-S − DeiT-S 的差值只描述，不判定。MiTA 与 DeiT 的差比这个参照还小时，不把差别归功于 top-k。
- **预试验的作用：** 用 P 估计配对差的标准差，预测在 F 上判定区间的半宽。如果预测半宽大于 0.015，就在论文中说明判定的分辨力有限。F 的图片数已经是全部，不再增加。
- **事后分析：** 看到正式结果之后才加的分析，一律标为"事后"。
