# 注意力预算研究：阶段一（预试验）报告

2026-11-03 · 代码 `efe6287` · Colab L4 · 预试验集 P（ImageNet-S 中按种子 0 抽出的 500 张，不参与正式判定）

**一句话：** 测量足够精确；DeiT-S 能找到制造高范数 token 的神经元，DeiT-B 找不到；高范数 token 只出现在 DeiT-S、DeiT-B 和两个 MiTA 模型里。

这里的数字都来自 500 张图，只用来定门槛和估计精度，**不作判定**。判定标准见 `docs/decisions.md` 的 B27–B31。

## 1. 哪些模型有高范数 token（T1）

"高范数图块"指块输入的长度超过本图中位数 3 倍的图块。下表是任一层有高范数图块的图片比例，以及完整注意力的预算落在高范数图块上的比例（第 9–12 层）。

| 模型 | 开始大量出现的层 | 第 9–12 层预算在高范数图块上的比例 |
| --- | --- | --- |
| DeiT-S | 6 | 5%–8% |
| DeiT-B | 7 | 20%–44%（第 11 层最高） |
| MiTA-DeiT-S | 6 | 39%–51% |
| MiTA-DeiT-T | 7 | 30%–51% |
| DeiT-T、DeiT-III-S、DINO | 没有 | ≈ 0 |

**举例：** MiTA-DeiT-S 第 10 层，每个 query 平均把一半的注意力给了高范数图块，给物体的只有 30%。普通 DeiT-S 同一层给高范数图块的只有 8%，给物体的有 41%。

**值得注意：** MiTA 的预算被高范数图块拿走得比普通 DeiT 多得多。这与"top-k 让注意力更干净"的直观印象相反。这一点只作描述，正式结果出来后再讨论。

## 2. 高范数图块的 value 很短

在第 9–12 层，高范数图块的 value 长度只有普通图块中位数的 0.16–0.48 倍（DeiT-S 0.21–0.39，DeiT-B 0.19–0.27）。这符合 Fesser 等 2026 所说"空操作型"sink 的特征：注意力花在这里，但带回来的内容很少。是否真是空操作，要看 T4 的三种处理（B29、B31）。

## 3. 制造高范数 token 的神经元（T2，关卡 H3）

| 模型 | L* | 结果 | 依据 |
| --- | --- | --- | --- |
| DeiT-S | 6 | **通过**，n = 8 | 8 个神经元（第 4–5 层）移到额外 token 后，第 6 层及以后的高范数图块减少 92.7%，预测一致 99.0%；随机 8 个神经元：−4.3% |
| DeiT-B | 7 | **未通过** | n = 32 时只减少 44.9%（n = 16 时 41.2%），达不到 80% |
| DINO | 无 | 阴性对照，符合预期 | 没有任何层有足够多的高范数图块 |

按 B30、B31：
- DeiT-S 做测试时额外 token 的因果干预（T6），H6 只在 DeiT-S 上判定；
- DeiT-B 的 RQ3 改为描述性分析，H6（DeiT-B）记为"无法检验"。

**这本身也是一个发现：** 在更大的有监督模型 DeiT-B 中，高范数 token 不是由少数几个 FFN 神经元造成的，至少按 Jiang 等的搜索方法找不到。

## 4. 测量精度

正式集有 11,919 张图。按预试验中配对差的标准差（0.08–0.13）估算，99.5% 判定区间的半宽约为 0.002–0.003，远小于最小差 0.03。所以正式判定不会因为图片太少而落入"不确定"。

预试验中的配对差（扣除两个模型各自高范数位置的并集后，第 9–12 层的同环富集）如下，只供参考：

| 比较 | 差值 [95% 区间] |
| --- | --- |
| DINO − DeiT-S | 0.037 [0.027, 0.048] |
| DINO − MiTA-DeiT-S | 0.041 [0.030, 0.051] |
| DINO − DeiT-T | 0.050 [0.040, 0.061] |
| DINO − MiTA-DeiT-T | 0.000 [−0.009, 0.010] |
| DINO − DeiT-III-S | 0.047 [0.037, 0.057] |
| DINO − DeiT-B | 0.071 [0.061, 0.080] |
| MiTA-DeiT-S − DeiT-S | −0.014 [−0.022, −0.007] |

| DeiT-III-S − DeiT-S（参照） | −0.006 [−0.014, 0.003] |

如果正式结果与预试验相近，H1 会因 MiTA-DeiT-T 而不成立，H2 在 Tiny 这组可能不成立或不确定。判定标准不会因此改动。

## 6. 12 层注意力全部删掉（T7）

数据是论文执行图用的 5,000 张 ImageNet 图片，每个模型都用它自己的预处理。表中数字是 top-1 与原模型一致的比例。

| 模型 | 12 层全部删掉 | 只删掉一层 |
| --- | --- | --- |
| DeiT-S | 0.1% | 92.8%–97.2%（第 1 层 68.8%） |
| DINO | 0.1% | 85.7%–95.0%（第 1 层 0.2%） |
| DeiT-B | 0.2% | 93.7%–97.8%（第 1 层 87.8%） |

**结论：** 只删掉一层注意力，大多数层仍保留九成以上的预测。所以"只替换一层仍保留 92%–96%"区分不了"名单对"和"这层本来就不重要"。12 层同时按名单计算保留 72%（DeiT-S），随机名单只有 9%，完全没有注意力只剩 0.1%，这才是有力的证据。
