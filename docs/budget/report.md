## 1. 三个判定

"明显"指差值至少 0.03（同环物体富集，第 9–12 层）。区间是 Bonferroni 校正后的 99.5% 配对 bootstrap 区间，重抽样 10,000 次。

| 假设 | 内容 | 判定 | 原因 |
| --- | --- | --- | --- |
| H1 | DINO 比 6 个有监督模型都明显更聚焦物体 | **不成立** | 对 5 个模型成立；对 MiTA-DeiT-T 不成立：差 −0.002 [−0.005, 0.000] |
| H2 | 两组配对中 top-k 训练都没有明显提高物体聚焦 | **不成立** | Small 组成立：−0.011 [−0.013, −0.008]；Tiny 组不成立：+0.037 [0.035, 0.040] |
| H6 | 移走制造高范数 token 的神经元，物体聚焦没有明显提高 | **成立**（只在 DeiT-S 上检验） | +0.006 [0.005, 0.007]，远低于 0.03。DeiT-B 没通过 H3 关卡，记为"无法检验" |

各个比较的明细如下。

| 比较 | 差值 | 99.5% 区间 | 单项判定 |
| --- | --- | --- | --- |
| DINO − DeiT-S | 0.037 | [0.034, 0.040] | 成立 |
| DINO − MiTA-DeiT-S | 0.036 | [0.033, 0.039] | 成立 |
| DINO − DeiT-T | 0.051 | [0.048, 0.054] | 成立 |
| DINO − MiTA-DeiT-T | −0.002 | [−0.005, 0.000] | 不成立 |
| DINO − DeiT-III-S | 0.043 | [0.039, 0.046] | 成立 |
| DINO − DeiT-B | 0.065 | [0.062, 0.068] | 成立 |
| MiTA-DeiT-S − DeiT-S | −0.011 | [−0.013, −0.008] | 成立 |
| MiTA-DeiT-T − DeiT-T | +0.037 | [0.035, 0.040] | 不成立 |
| DeiT-S：R2 − R0（移走神经元） | +0.006 | [0.005, 0.007] | 成立 |
| 参照：DeiT-III-S − DeiT-S（95%） | −0.002 | [−0.004, −0.001] | 只描述 |

**读法：** 换一种有监督训练配方（DeiT-III），物体聚焦只差 0.002。两组 MiTA 配对的差别（−0.011 和 +0.037）都比这个参照大，所以它们确实来自 top-k 训练，而不是普通的训练差异。但两组的方向相反。

## 2. 预算花在哪里（RQ1，图 18）

| 模型 | 第 11 层：物体 / 高范数 / CLS | 第 9–12 层同环富集（扣掉高范数 / 全部图块） |
| --- | --- | --- |
| DeiT-S | 40% / 5% / 16% | 0.160 / 0.139 |
| MiTA-DeiT-S | 26% / **50%** / 0% | 0.151 / 0.100 |
| DeiT-T | 42% / 0% / 16% | 0.149 / 0.149 |
| MiTA-DeiT-T | 44% / **31%** / 1% | 0.192 / 0.129 |
| DeiT-III-S | 34% / 0% / 31% | 0.157 / 0.156 |
| DeiT-B | 29% / **43%** / 1% | 0.130 / 0.080 |
| DINO | 52% / 0% / 7% | 0.199 / 0.199 |

**要点：**
1. **高范数 token 只出现在四个有监督模型里：** DeiT-S、DeiT-B 和两个 MiTA。在 MiTA 和 DeiT-B 的深层，它们拿走 30%–50% 的预算。
2. **top-k 训练让高范数 token 拿走更多预算。** 例如在第 11 层，MiTA-DeiT-S 有 50% 的预算给了高范数图块，DeiT-S 只有 5%。
3. **"扣不扣高范数图块"会改变结论。** 保留全部图块时（也就是注意力图平常的画法），两个 MiTA 模型都比各自的 DeiT **更不**聚焦：
   - MiTA-DeiT-S − DeiT-S = −0.039 [−0.040, −0.037]
   - MiTA-DeiT-T − DeiT-T = −0.020 [−0.022, −0.018]

   这两个是 95% 区间，属于次要结果。只有扣掉 MiTA 的大量高范数图块后，Tiny 的 MiTA 才显得更聚焦。
4. **最后一层离开物体，与高范数 token 无关。** 扣掉高范数图块后，所有 7 个模型第 12 层的富集都低于第 8–11 层的最高值：DeiT-B −0.123，DINO −0.057，DeiT-T −0.023。离开的预算去向因模型而异：
   - DeiT-S 主要转给 CLS（16% → 22%）；
   - DeiT-B 主要转给背景。

## 3. 高范数 token 上的预算有没有被用上（T4，图 20 左）

做法是在所有出现高范数图块的层上，同时让所有 query 不再读取它们，然后看模型对原来答案的把握下降多少。

| 模型 | 不读高范数 | C1：同样数量、最受关注的普通图块 | C2：同样数量、同距离环随机 | value 置零 | value 换成平均值 |
| --- | --- | --- | --- | --- | --- |
| DeiT-S | 0.009 | 0.020 | 0.001 | 0.000 | −0.001 |
| DeiT-B | **0.052** | 0.037 | 0.002 | 0.021 | −0.005 |

（单位是 nats：原 top-1 类别的 log 概率下降多少。）

**判断（B29、B31 的规则）：**
- **DeiT-B：用上了。** 拿掉高范数图块造成的下降比 C1、C2 都大，差值的区间分别是 [0.009, 0.021] 和 [0.048, 0.052]。但把它们的 value 换成数据集平均值后几乎没有影响。所以它们带回的主要是一个**每张图都差不多的量**，像一个常数项。按登记的门槛，"置零"的影响（0.021）没有超过 0.05，所以 sink 类型记为"不确定"，没有判为"常数偏置型"。
- **DeiT-S：不确定。** 下降介于 C1 和 C2 之间，而且所有影响都很小：一致率约 99%，下降不到 0.01 nats。
- **两个模型的高范数 value 都很短：** 只有普通图块的 0.29 倍（DeiT-S）和 0.23 倍（DeiT-B），符合"空操作型"的一个特征。输出有效秩只在 DeiT-S 中明显偏低：被高范数主导的 head 只有同层其他 head 的 0.40 倍。

**举例：** 在 DeiT-B 第 11 层，6 个高范数图块收到约 43% 的注意力。不让任何 query 读它们，比拿掉 6 个最受关注的普通图块更伤预测。但只要给它们一个固定的平均 value，模型就和原来几乎一样。

## 4. 移走制造高范数 token 的神经元（T6，DeiT-S，图 20 右）

把 DeiT-S 第 4–5 层的 8 个 FFN 神经元的激活移到一个额外 token 上（Jiang 等 2025 的做法），模型不重新训练。

| 条件 | 第 6 层以后的高范数图块 | ImageNet 准确率 | 富集（扣掉原高范数位置） |
| --- | --- | --- | --- |
| R0 原模型 | — | 79.83% | 0.160 |
| R1 只加额外 token | +4.5% | 79.78% | 0.163 |
| **R2 移走找到的神经元** | **−91.5%** | **79.83%** | **0.166** |
| R3 随机神经元（5 个种子） | +3.8% 到 +5.0% | 79.75%–79.80% | 0.163–0.164 |
| R4 激活相当的神经元 | +4.4% | 79.77% | 0.162 |
| R5 直接置零（不加 token） | −85.0% | 79.79% | 0.150 |

- **操作检查 H4 通过：** 高范数图块减少 91.5%（门槛是 80%），准确率不变。
- **腾出的预算去了哪里**（第 9 层）：
  - 高范数图块：8.3% → 0.4%
  - 额外 token：0 → 5.9%
  - 物体：40.6% → 41.1%
  - 背景：40.9% → 42.5%

  **大部分转给了额外 token**，这和 Fesser 等 2026 的发现一致：register 只是挪动了 sink。
- **把神经元直接置零（R5）：** 腾出的预算主要流向背景（第 9 层 40.9% → 46.0%），物体聚焦反而略降（0.150）。
- **最后一层的下降仍在：** R2 中物体预算从第 11 层的 39.8% 降到第 12 层的 30.6%，和原模型（40.2% → 31.5%）几乎一样。

## 5. 复核 MiTA 图 4（RQ2 第 3 步）

按 MiTA 论文图 4 的画法，取每层所有 query 读过的 token 的并集。DeiT 用每个 query 注意力最高的 25 个 token 作同等画法。

| 模型 | 第 12 层选中的 token | 其中物体比例 | 扣除中心偏差后的富集 |
| --- | --- | --- | --- |
| MiTA-DeiT-S | 48% | 47% | 0.058 |
| DeiT-S（同等画法） | 42% | 52% | 0.092 |
| MiTA-DeiT-T | 37% | 51% | 0.086 |
| DeiT-T（同等画法） | 37% | 54% | 0.108 |

**结论：** 按这种画法，普通 DeiT 的深层同样只剩一小部分 token，而且这些 token 更偏向物体。所以 MiTA 图 4 中"深层只剩与类别相关区域"的印象，并不是 top-k 训练特有的。

## 6. 对主问题的回答

**ViT 的注意力预算花在哪里？**
- 在有监督模型的深层，相当一部分预算花在少数高范数 token 上（DeiT-B 第 11 层是 43%）。这些 token 的 value 很短，带回的内容接近常数。
- 在 DeiT-B 中，这部分预算确实被用上了；但起作用的似乎是"有一个固定的量可以读"，而不是这些 token 各自携带的图片信息。

**哪些杠杆能把预算引向物体？**
- **杠杆 B（移走制造 sink 的神经元）不能。** 腾出的预算大多转给新的停靠点（额外 token），物体只多拿到约 0.5 个百分点，富集只提高 0.006。
- **杠杆 A（top-k 训练）的效果取决于怎么看：**
  - 按注意力图平常的画法，MiTA 比 DeiT 更不聚焦，因为它把更多预算交给了高范数 token；
  - 扣掉这些 token 后，Small 组略降，Tiny 组明显升高。
  - 每个模型只训练过一次，所以只能说"在这两组配对中，效应的方向依赖规模"。
- **训练目标：** 自监督的 DINO 没有高范数 token，聚焦程度高于 5 个有监督模型，但与 MiTA-DeiT-T（扣掉高范数后）相当。所以"决定聚焦的是训练目标"只能作为倾向，不能作为全称结论。

**对可解释性的意义：** "注意力图看起来更干净"不能直接当作"模型更关注物体"。去掉高范数 token 后，腾出的注意力会去新的停靠点；而 top-k 稀疏化会制造更多高范数 token。解读注意力图时，必须同时报告扣除中心偏差的结果，以及高范数 token 拿走了多少预算。

## 8. 局限

- 每个模型只训练过一次。区间只反映图片之间的波动，不反映"重新训练一次"的波动。
- DeiT 由官方训练，MiTA 由其作者用同一训练脚本训练，但不是同一次实验。
- RQ3 的因果干预只在 DeiT-S 上完成；DeiT-B 找不到少数几个制造 sink 的神经元。sink 分型在两个模型上都按登记门槛记为"不确定"。
- 深层 token 已不完全代表原来的图块：第 12 层只有 15%–25% 能被认出原位置。所以"预算去了哪里"指的是去了哪些 token 位置。
