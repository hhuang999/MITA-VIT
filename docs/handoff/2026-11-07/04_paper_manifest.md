## 1. 论文的主张（叙事说明）

论文题目：*Attention as Fast Weights: Reading, Diagnosing, and Correcting Attention Maps in Vision Transformers*。课程 workshop 级报告，正文 4 页，NeurIPS 模板，截止 2026-12-11。

**视角：** 一个注意力头对每张图都是一个临时的两层网络。key 是第一层权重，softmax 是激活函数，value 是第二层权重，每个 token 是一个隐藏单元。W_Q、W_K、W_V、W_O 是慢权重，K、V 是快权重。“收到的注意力”图（R0）就是在读隐藏单元的激活，并把单元 j 画在图块 j 的位置。

**例子：** 好比用“每个员工收到多少封邮件”来判断谁重要。这个读法默认了三件事：邮件数随图片变化（M1）；员工 j 还坐在原来的工位 j（M2）；收到的邮件多就是贡献大（M3）。

**三个研究问题和结论：**

| 问题 | 结论（论文正文的写法） |
| --- | --- |
| RQ1 读 | 注意力读到的单元确实被模型执行：每个区域只读 16 个单元、12 层同时限制，仍保留大部分预测，随机单元不行。R0 指向物体、与人一致，但明显不如 GAE。 |
| RQ2 诊断 | 三个前提中两个在深层失效：M2 在三个模型都失效；M3 只在有监督模型失效；M1 基本成立（与图片无关的部分很小，且近似同心圆）。 |
| RQ3 修正 | 只有按贡献计分（C3）既胜过 R0、又胜过它的替身，而且只在 M3 失效的模型上有效（DINO 上不变）。C1 只等于去掉中心偏差。C2 让读法全面变差，比同等模糊还差。改模型（测试时 register、top-k 训练）不如改读法。合用不稳健。 |
| 为什么 C2 失败（第 4.5 节，版本 B，作者 2026-11-08 确定） | C2 失败的机制尚未确定；探针远距离错误、固定偏好、探针容量、token 全局化四个原因都已排除（E-C2 的 H-a、H-b；X5 M-weak；X4 H-global 不成立）。原候选解释“深层 token 变成全局信息”不再使用。 |

**主线：诊断能不能预测修正。** 三个前提里，两个对得上（M1 成立 → C1 无用；M3 只在有监督模型失效 → C3 只在那里有效），一个对不上（M2 处处失效，C2 处处有害）。

**写作约束（第二阶段的 README 也要遵守）：**
- 不说“两个可分离的原因”，不说 C2 的问题“不可修”。
- 不说按值向量长度加权是我们发明的（Kobayashi 等 2020、SNNA 已提出）。
- 事后提出的分析一律标为“探索性”。
- P3（三者合用）如实报告为“部分成立”。
