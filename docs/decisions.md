# 决策日志

以下内容从 HANDOFF.md 第 7 节归档；研究设计变更先列提议，经用户同意后执行。


## 已确定

| 决策 | 内容 | 原因 |
| --- | --- | --- |
| 研究方向 | 可解释性；把 MiTA 的机制当工具，去解释一个普通的、未改动的 ViT | 用户被 MiTA 的两个 idea 打动（快权重视角、深层自动“剪枝”聚焦物体），希望以 MiTA 为思路起点做可解释性 |
| 解释的形式 | 读取模式：从原模型的 Q、K 中读出说明书，不替换注意力 | 读取不改动模型，比“把 MiTA 插进模型当探针”更干净 |
| 忠实性检验 | 执行模式：只按说明书计算，看预测一致率 | 把忠实性变成可测数字，对应 ERASER 的“充分性”思路 |
| 研究结构 | 3 个 RQ，3 张主图（外加论文中的方法示意图） | 课程项目重视论证闭环，不追求大规模对比 |
| 核心对比只有 4 个 | RQ1：随机读取集合、K-means 分组；RQ3：CLS 注意力热图、中心高斯图 | 每个对比都服务于我们自己的分析 |
| 分层交付 | 按 RQ1 → RQ2 → RQ3 推进，每一步都是闭环，做到哪写到哪 | 时间不确定时保证有完整成果 |
| 可读性的定义 | 说明规模 m×k | 简单、诚实；用户调研超出范围 |
| 主执行范围 | RQ1 所有层同时替换；RQ2 每次替换一层 | 前者一个数字回答主问题，后者定位哪层难 |
| 严格版本为主 | 核心实验只用严格版本；宽松版本（完整 MiTA）是选做 | 严格版本直接对应“说明书够不够” |
| 主设置 | m = 16 固定，k ∈ {4, 8, 16, 32, 64}；RQ2 用 k ∈ {8, 32} | 曲线一目了然；其他 m 放附录 |
| 模型 | DeiT-S（timm） | 小、标准、有分类头；与 DINO ViT-S/16 架构相同，便于选做对比 |
| 数据 | Imagenette 调试；ImageNet 验证集 5,000 张（种子 0）；Oxford-IIIT Pet 测试集 | 规模足够、获取简单；Pet 有前景标注 |
| 不用 flash-attn | 自己用掩码在完整注意力矩阵上实现 | N = 197 很小，掩码实现简单且精确 |
| 写作基调 | 讲清楚我们自己的贡献，不写成防御性的“逐条回应质疑” | 用户明确要求 |
| 文档风格 | 直接、具体、带数字和公式，避免元解释和堆砌术语 | 用户是大三本科生，要求清晰易懂 |
| 贡献表述 | 不主张“机制是新的”（来自 Clustered Attention / MiTA），也不主张“注意力等价于快权重 MLP”是新结论（已有代数事实） | 新意在于用途（可读解释）和检验方式（执行） |

## 已放弃

| 方案 | 放弃原因 |
| --- | --- |
| 加速方向：在深层丢弃从未被选中的 token，测提速 | 需要与成熟的 token pruning（EViT、ToMe 等）竞争；用户更想做可解释性 |
| 研究 MiTA 本身“为什么会聚焦物体” | 用户希望把 MiTA 当工具去解释别的模型，而不是研究 MiTA |
| 把 MiTA 注意力插进标准 ViT 当探针，再解释替换后的模型 | 替换后已不是原模型；改为“读取（不改模型）+ 执行检验” |
| 跨模型测量注意力的“有效宽度” | 注意力熵、距离的跨监督方式比较已有大量工作（如 Teaching Matters, CVPR 2023）；推理时 top-k 截断可行也已知（Gupta 2021） |
| 以 Waterbirds 捷径诊断为主线 | Waterbirds 上的定性注意力可视化已很多；降为选做应用 |
| 用文本作 landmark 解释 CLIP | 风险高：CLIP 的 patch token 与文本空间对齐较差 |
| 7 条假设、4 个实验层次、十几种对比方法的大设计 | 过于复杂，偏离论证闭环；收敛为 3 个 RQ + 4 个对比 |
| 用户调研衡量可读性 | 超出课程项目范围 |

## RQ3 扩展：事先约定（2026-10-26，用户已授权；运行前冻结）

以下定义在读取扩展诊断数据之前登记，不按结果调整。既有 RQ1/RQ2 和原 RQ3 文件保留。

- **E01 汇聚点。** 每图每层 block 输入、norm1 之前的 patch token L2 范数，严格大于该图该层所有 patch 范数中位数的 3 倍；偶数个 token 的中位数取中间两数平均。敏感性阈值为 2 和 5，均报告，不替换主阈值。CLS/register 不进入中位数。这个名称是操作定义，不预先断言其功能。逐层热图用同层定义；9–12 层平均热图的排除集合为四层汇聚点的并集，CLS 图用第 12 层定义。B2 启用条件：3 倍阈值下，9–12 层任一层存在汇聚点的图片比例至少 10%。
- **E02 空间标签与成分。** 沿用相同 resize/crop、最近邻 mask、非边界像素前景占比 ≥0.5；高范数 patch 优先归为汇聚点，其余有效 patch 分前景/背景。全边界 patch 单列 unknown，CLS 与每个 register 单列，分母为全部选中次数，保证总和为 1；空间热图仍排除前缀/unknown。B3 的前景删除包含前景中的汇聚点，背景删除仅非汇聚点，因此这些干预不是互斥的三分类。
- **E03 B3 替换。** 原模型前向保存完整区域打分、top-k 集合和 query 路由。仅指定层（9–12 或 1–12）执行严格 mask，其余层原样；所有干预共享冻结说明书。移除目标类别，再依原始区域打分从高到低加入非目标且不重复的 token，直到 k；保留原集合中非目标项。打分并列时补选按 token 编号升序；原 top-k 保留原实现。类别删除不删除 CLS。随机对照种子 0–4：每个图/层/head/区域均匀无放回删除与汇聚点删除数相同的原集合成员（允许 CLS），从原集合以外、未删除的最高排名 token 补满，避免把随机删除项立即补回。
  若某图某干预层非目标 token 总数小于 k，则该图该范围的对应干预不可执行，记 NaN 与原因，绝不补回禁用类别、重复 token 或减小 k。所有 3,669 张都处理并报告覆盖；每种干预与基准用其可执行图片配对，跨类别排序另用所有干预共同可执行图片。报告删除数量与剂量不等的局限，不能把总影响直接解释为单 token 重要性。随机对照先逐图平均五种子，再对图片 bootstrap；另列逐种子结果。
- **E04 偏心分组。** 在变换后的 224×224 trimap 上用 label=1 像素质心与图像中心 (111.5,111.5) 的欧氏距离，除以图像边长。使用全集距离的 1/3、2/3 分位数分居中/中等/偏心，边界值归较低组；没有前景像素记缺失。分组只依 mask，不依热图；各模型使用相同图像几何。B4 主设置和 k=32 均报告，B2 被跳过时相应方法不生成。
- **E05 随机/统计。** 均匀随机热图是每图每 token 独立 Uniform(0,1)，CPU NumPy seed=0，按图像索引固定；所有 k 共用。期望 pointing 和质量均为有效前景 token 占比，有限随机实现另报 CI。所有估计与差值使用图片级 bootstrap 1,000 次、seed=0、95%；缺失只在对应统计排除并报 n。最高点并列沿用行优先首个有效 token。范数直方图用固定 logspace(1e-3,1e5,161) 箱，另存超界计数；频率图给每位置 CI，top10 按频数降序、位置升序。
- **E06 B5 可比性。** 按用户指定的两种 timm DINOv2-S/14 checkpoint，固定下载 revision；224 输入、16×16 patch 网格、m=16、k=16/32，observe-only。为控制图像几何，沿用 DeiT 的 resize248/crop224 和归一化（核对两模型 mean/std），patch 标签改为 14×14 像素。CLS 与四个 register 排除区域池化，作为 key 可被选中，分别统计。两者是分别训练的权重，不能声称相同权重上仅开关 register；该配对是机制假设的模型对照，不是单因素训练因果实验。官方来源：timm 两张模型卡及 https://arxiv.org/abs/2309.16588 。
- **E07 执行环境与顺序。** 沿用已验证的本地 RTX 4060、项目 .venv、FP32、batch32，不启动此前无资源的 HPC。A→B1→B2→B3→B4→B5，每项归档提交推送。用户提到的 RQ1 统一硬件重跑/RQ2 独立累积估算此前未执行；在本任务之后另存补充目录，只添加对照分析，不覆盖原结果或改设置。独立累积估算定义为十二个单层一致率的乘积，图片配对 bootstrap 同步重采样十二层；这是独立性假设参照，不是实际联合干预预测。

## P1 实现约定（2026-10-24）

- 按设计书 §5 的“先读原模型，再执行说明书”，先保存原模型各层的读取集合和路由，执行时固定它们。后续层使用执行过程产生的 Q/K/V 打分，但不重选读取集合。在线重新计算说明书是另一种干预，本次未实现。
- timm 1.0.30 的 Attention 已原生支持布尔 `attn_mask`。读取通过 QKV 输出 hook 观察，执行通过 attention pre-hook 注入掩码，沿用原有归一化、缩放、softmax、投影及融合路径；无需复制其 forward。上下文退出时移除 hook。
- 网格遵循交接文档指定的 adaptive average pooling。14→4 的单轴窗口为 `[0,4)`、`[3,7)`、`[7,11)`、`[10,14)`，相邻窗口会重叠；16 个 landmark 对应这些可见区域，不把它们称为不相交划分。CLS 不参加池化。
- K-means 使用欧氏距离的 Lloyd 更新，网格中心初始化，固定 10 次迭代；空簇保留前一次中心。最终 query 路由仍是点积 argmax，与网格版相同。
- 随机对照仅替换读取集合，保留路由；由调用方维护独立、带种子的 torch.Generator，跨 batch 连续取样，不影响模型的全局 RNG。
- 主指标是预测一致率；KL 定义为 `KL(p_original || p_executed)`。bootstrap 在图片维度成对重采样，先对随机对照的种子求平均；随机种子之间的波动另行报告。
- 当前真实数据验收使用 Imagenette 全部 3,925 张验证图，沿用 timm 默认 eval 预处理。它不替代尚未取得的 ImageNet 5,000 张恒等验收。
