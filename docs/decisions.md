# 决策日志

## 已确定

| 决策 | 内容 | 原因 |
| --- | --- | --- |
| 研究方向 | 可解释性；把 MiTA 的机制当工具，去解释一个普通的、未改动的 ViT | 用户被 MiTA 的两个 idea 打动（快权重视角、深层自动“剪枝”聚焦物体），希望以 MiTA 为思路起点做可解释性 |
| 解释的形式 | 读取模式：从原模型的 Q、K 中读出说明书，不替换注意力 | 读取不改动模型，比“把 MiTA 插进模型当探针”更干净 |
| 忠实性检验 | 执行模式：只按说明书计算，看预测一致率 | 把忠实性变成可测数字，对应 ERASER 的“充分性”思路 |
| 研究结构 | 3 个 RQ，3 张主图（外加论文中的方法示意图） | 课程项目重视论证闭环，不追求大规模对比 |
| 核心对比只有 4 个 | RQ1：随机读取集合、K-means 分组；RQ3：CLS 注意力热图、中心高斯图 | 每个对比都服务于我们自己的分析 |
| 分层交付 | 按 RQ1 → RQ2 → RQ3 推进，每一步都是闭环，做到哪写到哪 | 时间不确定时保证有完整成果 |
| 可读性的定义 | 说明规模 m×k | 简单、诚实；用户调研超出范围 |
| 主执行范围 | RQ1 所有层同时替换；RQ2 每次替换一层 | 前者一个数字回答主问题，后者定位哪层难 |
| 严格版本为主 | 核心实验只用严格版本；宽松版本（完整 MiTA）是选做 | 严格版本直接对应“说明书够不够” |
| 主设置 | m = 16 固定，k ∈ {4, 8, 16, 32, 64}；RQ2 用 k ∈ {8, 32} | 曲线一目了然；其他 m 放附录 |
| 模型 | DeiT-S（timm） | 小、标准、有分类头；与 DINO ViT-S/16 架构相同，便于选做对比 |
| 数据 | Imagenette 调试；ImageNet 验证集 5,000 张（种子 0）；Oxford-IIIT Pet 测试集 | 规模足够、获取简单；Pet 有前景标注 |
| 不用 flash-attn | 自己用掩码在完整注意力矩阵上实现 | N = 197 很小，掩码实现简单且精确 |
| 写作基调 | 讲清楚我们自己的贡献，不写成防御性的“逐条回应质疑” | 用户明确要求 |
| 文档风格 | 直接、具体、带数字和公式，避免元解释和堆砌术语 | 用户是大三本科生，要求清晰易懂 |
| 贡献表述 | 不主张“机制是新的”（来自 Clustered Attention / MiTA），也不主张“注意力等价于快权重 MLP”是新结论（已有代数事实） | 新意在于用途（可读解释）和检验方式（执行） |

## 已放弃

| 方案 | 放弃原因 |
| --- | --- |
| 加速方向：在深层丢弃从未被选中的 token，测提速 | 需要与成熟的 token pruning（EViT、ToMe 等）竞争；用户更想做可解释性 |
| 研究 MiTA 本身“为什么会聚焦物体” | 用户希望把 MiTA 当工具去解释别的模型，而不是研究 MiTA |
| 把 MiTA 注意力插进标准 ViT 当探针，再解释替换后的模型 | 替换后已不是原模型；改为“读取（不改模型）+ 执行检验” |
| 跨模型测量注意力的“有效宽度” | 注意力熵、距离的跨监督方式比较已有大量工作（如 Teaching Matters, CVPR 2023）；推理时 top-k 截断可行也已知（Gupta 2021） |
| 以 Waterbirds 捷径诊断为主线 | Waterbirds 上的定性注意力可视化已很多；降为选做应用 |
| 用文本作 landmark 解释 CLIP | 风险高：CLIP 的 patch token 与文本空间对齐较差 |
| 7 条假设、4 个实验层次、十几种对比方法的大设计 | 过于复杂，偏离论证闭环；收敛为 3 个 RQ + 4 个对比 |
| 用户调研衡量可读性 | 超出课程项目范围 |

## RQ3 扩展：事先约定（2026-10-26，用户已授权；运行前冻结）

以下定义在读取扩展诊断数据之前登记，不按结果调整。既有 RQ1/RQ2 和原 RQ3 文件保留。

- **E01 汇聚点。** 每图每层 block 输入、norm1 之前的 patch token L2 范数，严格大于该图该层所有 patch 范数中位数的 3 倍；偶数个 token 的中位数取中间两数平均。敏感性阈值为 2 和 5，均报告，不替换主阈值。CLS/register 不进入中位数。这个名称是操作定义，不预先断言其功能。逐层热图用同层定义；9–12 层平均热图的排除集合为四层汇聚点的并集，CLS 图用第 12 层定义。B2 启用条件：3 倍阈值下，9–12 层任一层存在汇聚点的图片比例至少 10%。
- **E02 空间标签与成分。** 沿用相同 resize/crop、最近邻 mask、非边界像素前景占比 ≥0.5；高范数 patch 优先归为汇聚点，其余有效 patch 分前景/背景。全边界 patch 单列 unknown，CLS 与每个 register 单列，分母为全部选中次数，保证总和为 1；空间热图仍排除前缀/unknown。B3 的前景删除包含前景中的汇聚点，背景删除仅非汇聚点，因此这些干预不是互斥的三分类。
- **E03 B3 替换。** 原模型前向保存完整区域打分、top-k 集合和 query 路由。仅指定层（9–12 或 1–12）执行严格 mask，其余层原样；所有干预共享冻结说明书。移除目标类别，再依原始区域打分从高到低加入非目标且不重复的 token，直到 k；保留原集合中非目标项。打分并列时补选按 token 编号升序；原 top-k 保留原实现。类别删除不删除 CLS。随机对照种子 0–4：每个图/层/head/区域均匀无放回删除与汇聚点删除数相同的原集合成员（允许 CLS），从原集合以外、未删除的最高排名 token 补满，避免把随机删除项立即补回。
  若某图某干预层非目标 token 总数小于 k，则该图该范围的对应干预不可执行，记 NaN 与原因，绝不补回禁用类别、重复 token 或减小 k。所有 3,669 张都处理并报告覆盖；每种干预与基准用其可执行图片配对，跨类别排序另用所有干预共同可执行图片。报告删除数量与剂量不等的局限，不能把总影响直接解释为单 token 重要性。随机对照先逐图平均五种子，再对图片 bootstrap；另列逐种子结果。
- **E04 偏心分组。** 在变换后的 224×224 trimap 上用 label=1 像素质心与图像中心 (111.5,111.5) 的欧氏距离，除以图像边长。使用全集距离的 1/3、2/3 分位数分居中/中等/偏心，边界值归较低组；没有前景像素记缺失。分组只依 mask，不依热图；各模型使用相同图像几何。B4 主设置和 k=32 均报告，B2 被跳过时相应方法不生成。
- **E05 随机/统计。** 均匀随机热图是每图每 token 独立 Uniform(0,1)，CPU NumPy seed=0，按图像索引固定；所有 k 共用。期望 pointing 和质量均为有效前景 token 占比，有限随机实现另报 CI。所有估计与差值使用图片级 bootstrap 1,000 次、seed=0、95%；缺失只在对应统计排除并报 n。最高点并列沿用行优先首个有效 token。范数直方图用固定 logspace(1e-3,1e5,161) 箱，另存超界计数；频率图给每位置 CI，top10 按频数降序、位置升序。
- **E06 B5 可比性。** 按用户指定的两种 timm DINOv2-S/14 checkpoint，固定下载 revision；224 输入、16×16 patch 网格、m=16、k=16/32，observe-only。为控制图像几何，沿用 DeiT 的 resize248/crop224 和归一化（核对两模型 mean/std），patch 标签改为 14×14 像素。CLS 与四个 register 排除区域池化，作为 key 可被选中，分别统计。两者是分别训练的权重，不能声称相同权重上仅开关 register；该配对是机制假设的模型对照，不是单因素训练因果实验。官方来源：timm 两张模型卡及 https://arxiv.org/abs/2309.16588 。
- **E07 执行环境与顺序。** 沿用已验证的本地 RTX 4060、项目 .venv、FP32、batch32，不启动此前无资源的 HPC。A→B1→B2→B3→B4→B5，每项归档提交推送。用户提到的 RQ1 统一硬件重跑/RQ2 独立累积估算此前未执行；在本任务之后另存补充目录，只添加对照分析，不覆盖原结果或改设置。独立累积估算定义为十二个单层一致率的乘积，图片配对 bootstrap 同步重采样十二层；这是独立性假设参照，不是实际联合干预预测。

## P1 实现约定（2026-10-24）

- **B10 统计口径（所有新实验通用）。** 先按图片求每个量（随机对照先按种子 0–4 平均），再按图片配对 bootstrap 1,000 次（seed 0）求 95% 区间。"主比较"只有下面列出的几项；其余结果作为描述，不做判定。

- **B11 E4 补充定义。**
  - **SRG**（主忠实性指标）：横轴为删除的图块比例（0、1、2、4、8、16、32、64、98、147 个，除以 196），删除 0 个时一致率记为 1；用梯形法分别求"先删最不重要的"和"先删最重要的"一致率曲线下面积，SRG = 前者 − 后者。用原 top-1 概率求的 SRG 为次要指标。
  - **主合理性指标**：同距离环内富集（在离中心距离相同的图块之间比较，天然扣除中心）。次要：AUROC − 换掩码 AUROC，以及"（方法 − 中心）/（掩码 − 中心）"。
  - **主比较**（每个模型、每个数据集）：probe_mass 对 CLS 注意力、Rollout、GAE 的 SRG 之差和富集之差。
  - 第 5 节预测的判定方式："接近 0"指 95% 区间包含 0 或绝对值 < 0.02；"相当"指 SRG 之差的 95% 区间包含 0 或绝对值 < 0.05；"保留一半以上"指剩余比例的点估计 > 50%。
  - DeiT-B 的预测与 DeiT-S 相同。

- **B12 E7 人类一致性（ClickMe）。**
  - **数据**：Harmonization 发布的 ClickMe 验证集，17 个分片，逐个核对 Google Cloud Storage 的 MD5。图片来自 ImageNet **验证集**（Fel 等 2022 第 3 节原文："captured on the ImageNet validation set"），模型训练时没见过。几何与 Harmonization 相同：256 → 224 双线性缩放、不裁剪；人类图先缩到 64×64，用他们的 10×10 高斯核（σ = 10）模糊，再放大到 224。标签顺序已核对（DeiT-S 在前 128 张上 top-1 为 86.7%）。
  - **方法**：E4 的全部方法（去掉物体掩码），加平均人类图（Fel 等的中心偏差对照）和探针逐层图（第 1–12 层）。
  - **指标**：每张图的 Spearman 相关。像素级为主（Harmonization 指标：图块图双线性放大到 224×224 再比较），图块级为辅。"换图"对照：同一张图的分数与另一张图的人类图比较。**图片特异部分** = 本图 − 换图。Harmonization 的"对齐分数" = Spearman ÷ 0.65753（人类之间的一致程度）。

  - **预测**：(1) 平均人类图和中心高斯的原始 Spearman 高于所有探针变体（人类图偏向中心；Fel 等报告 84 个 CNN 中只有 42 个超过平均图）。(2) 所有非参照方法的图片特异部分 > 0。(3) DINO 探针的图片特异部分高于 DeiT-S 探针。(4) 探针对 GAE：不预测方向。

## 2026-10-31 研究定位 C 与补充实验 S1–S3（用户："选C，同意补1–3项实验，确认运行"；正式运行前登记）

- **B21 研究定位。** 论文定位为分析型研究：用经过执行验证的 top-k 读取名单（探针），在中心偏差对照下回答"预训练 ViT 逐层读了什么"。探针是测量工具，B11 的中心对照是方法学；论文不主张探针是最忠实的解释方法，如实报告它在删图块忠实性上低于 GAE、Grad-CAM。
  - 依据（2026-10-31 文献核查）：没有找到把 MiTA 式区域共享 top-k 名单用作普通 ViT 事后解释、并系统评估的工作。但三个组成部分都已有工作：机制和"测试时直接换成 MiTA 仍保留大部分性能"来自 MiTA（arXiv 2602.01219，附录 C）；去掉 top-k 后的打分就是 token 剪枝中"每个 token 收到的注意力之和"（PoWER-BERT ICML 2020、LTP KDD 2022）；"只按一小部分计算来检验"有 Vi-CD（arXiv 2604.14477）、LevAttention（ICLR 2025）。因此新意限定为：组合、中心对照下的评估，以及由此得到的发现。
  - SRG 的写法：引用 Blücher 等（arXiv 2401.06654）；"删 token + top-1 一致率"的版本与 LibraGrad（CVPR 2025）相同。

- **B22 S1：完整注意力加总（`attention_mass`）。**
  - **定义**：$s_j = \sum_{\ell=9}^{12}\sum_h\sum_i \mathrm{softmax}(q_i^\top K/\sqrt d)_j$，对全部 197 个 query、不加 top-k 限制，只取 196 个图块。层与 `probe_mass` 相同。它等于 k = 197 时的 `probe_mass`（单元测试检查），也就是 token 剪枝文献中的"收到的注意力"。
  - **在哪里比较**：E4 全部 10 个"数据集 × 模型"组合（配置、图片子集与 v3 相同，方法只有 `probe_mass` 和 `attention_mass`；`probe_mass` 在同一次运行中重算，用于同一运行内配对，并作为跨硬件复现检查）；E7（ClickMe，3 个模型）；E8（PartImageNet，3 个模型，只算解释图；"对得上"比例使用 v3 原运行的部件依赖结果，图片和模型相同）。
  - **指标**（`attention_mass − probe_mass`，按 B10 配对 bootstrap）：SRG（一致率）、同距离富集、ClickMe 图片特异 Spearman（像素级）、动物头部富集、部件"对得上"比例。描述性：ImageNet-S 上两张图逐图的 Spearman 相关（取自保存的分数）。
  - **判定**："相当"指差的 95% 区间含 0，或绝对值小于界限：SRG 0.05（同 B11），富集和图片特异 Spearman 0.02，头部富集 0.1。区间全在 0 以上或以下才记为"更高/更低"。
  - **预测**：(1) SRG 在 10 个组合中都"相当"；若有差别，`attention_mass` 更高（探针给没被读的图块打 0 分，它们之间只能随机排序）。(2) 同距离富集在 8 个组合中都"相当"。(3) ClickMe 图片特异 Spearman 在 3 个模型上都"相当"。(4) 头部富集：`probe_mass` 在 3 个模型上都高于 `attention_mass`（top-k 截断把注意力集中到少数 token 上）。(5) 部件"对得上"比例：不预测方向。(6) ImageNet-S 上两张图逐图 Spearman 的中位数在每个模型上都大于 0.5。(7) 复现：新运行的 `probe_mass` SRG 与 v3 的差在每个组合中都小于 0.01。
  - **事先约定的解读**：若 (1)–(3) 成立，解释图的质量来自"收到的注意力"本身，top-k 不改变它；论文写成"探针图约等于收到的注意力，top-k 带来的是可执行、可检验的名单"，若 (4) 成立再加"以及更集中的部件聚焦"。若 `attention_mass` 在 SRG 或人类一致上明显更好，就如实报告，论文用它画解释图、用读取名单做检验，部件和逐层发现对两种图都报告。若 `probe_mass` 明显更好，作为 top-k 的附加价值报告。

- **B23 S2：逐层曲线的对照。**
  - **定义**：`attention_layer{l}` = 只在第 l 层的完整注意力加总（所有头、所有 query）；`cls_layer{l}` = 第 l 层 CLS 对各图块的注意力（头平均），即现有 `cls_attention` 只取第 l 层。
  - **在哪里比较**：E7（逐层图片特异 Spearman）和 E8（逐层动物头部富集），3 个模型；与已有的 `probe_layer{l}` 同一运行重算。S3 的 ImageNet-S 运行另给出逐层同距离富集（描述性）。
  - **判定**："与探针的逐层规律相同"指 12 层均值曲线与探针曲线的 Pearson 相关 ≥ 0.8。
  - **预测**：(1) `attention_layer` 在 6 个"模型 × 指标"组合中都与探针规律相同。(2) DeiT-S、DeiT-B 的最后一层下降也出现在 `attention_layer` 中：两个指标上，第 12 层都低于第 8–11 层中均值最高的一层（配对区间不含 0）。(3) `cls_layer`：不预测。
  - **事先约定的解读**：若 (1)(2) 成立，逐层规律是模型注意力读取本身的性质，探针看到了，完整注意力也能确认；论文不再说"只有探针能看到"。若不成立，就把逐层规律报告为探针特有的现象并分析原因。

- **B24 S3：读取量中高范数 token 的占比（新实验 `layer_reading`）。**
  - **定义**：沿用 RQ3 诊断事先登记的定义（提交 6f9681e，`docs/analysis/rq3_diagnosis.md`）。第 l 层的高范数图块是指第 l 块输入（norm1 之前）的范数大于该图该层图块范数中位数 3 倍的图块。
  - **指标**（每张图、每层）：高范数图块的比例；`probe_layer{l}`、`attention_layer{l}`、`cls_layer{l}` 的读取量落在高范数图块上的比例。描述性：三类逐层图的物体质量占比和同距离富集。
  - **数据**：ImageNet-S 验证集 12,419 张，3 个模型。
  - **预测**：(1) DeiT-S、DeiT-B：探针第 12 层的高范数占比高于 v3 中 ClickMe 一致峰值所在层（DeiT-S 第 9 层，DeiT-B 第 6 层），配对区间不含 0。(2) 第 12 层上，DINO 探针的高范数占比低于 DeiT-S（按图片序号配对，区间不含 0）。(3) `cls_layer`：不预测。
  - **事先约定的解读**：若 (1)(2) 成立，有监督模型最后一层"离开物体"与读取高范数 token 同时发生，和 Darcet 等（ICLR 2024）的发现一致；只作关联描述，不作因果结论。

- **B28 测量与判定。**
  - **预算**：完整注意力（softmax）。MiTA 落在压缩槽上的权重按 S = softmax(landmark·key) 分回 token（M2）。
  - **物体聚焦**：第 9–12 层每个图块收到的完整注意力之和（`attention_mass`），用 `plausibility.measures` 计算同环物体富集。主结果把高范数位置标为无效后再计算：单个模型去掉第 9–12 层高范数位置的并集；配对比较去掉两个模型并集的并集；H6 去掉干预前的并集。包含全部图块的结果为次要结果。
  - **高范数**：第 l 块输入范数大于该图该层图块中位数 3 倍（B24 定义）。
  - **数据**：ImageNet-S 验证集按种子 0 打乱，前 500 张为预试验集 P（不参与判定），其余 11,919 张为正式集 F。所有模型统一使用 Resize 256（bicubic）+ 中心裁剪 224（M5）。

    - H1：6 个差值（DINO − 有监督）的区间下限都 > 0.03，记为成立；任一区间上限 < 0.03，记为不成立；其余记为不确定。

- **B29 "用没用上"与 sink 分型（M1）。**
  - **干预**：在出现高范数图块的所有层上，同时让所有 query 不再读取这些图块（在打分中设为 −∞ 后重新 softmax）。
  - **结果量**：原 top-1 类别的 log 概率下降，以及 top-1 一致率。
  - **主对照**：
    - C1：同层、同数量、收到注意力最多的普通图块。
    - C2：同层、同数量、同距离环内随机选取的普通图块，种子 0–4 先逐图平均。
  - **次要对照**：拿掉"同样多注意力"的普通图块，只在能凑够的层做，并报告实际拿掉的注意力量。

- **B45 E-C2 的定义与描述性标准（运行前登记）。**
  - **材料**：只用已保存的东西。
    - 位置探针和模糊宽度 σ：`experiments/2026-11-05_diagnose_probe_{model}/probes.npz`。
    - 2,000 张测试留出图片：同一运行 `heldout.json` 的第 2,001–4,000 行，不参与探针训练。

  - **E-C2-1 探针误差的空间分布**（三个模型，第 6–12 层，测试留出图片的每个图块 token）。P 是探针给出的 196 个位置的概率，j 是 token 原来的位置，距离用欧氏距离、以图块为单位。指标：
    - 精确正确率：P 最大的位置就是 j；
    - top-5 正确率；
    - 期望距离误差：Σ_p P(p) · ‖p − j‖；
    - 落在 j 的 3×3 邻域内的概率；
    - 落在距离 > 3 个图块处的概率；
    - **错误中的远距离比例**：距离 > 3 的概率 ÷（1 − P(j)）。
    - 同等模糊（该层 σ 的高斯核，每行在网格内归一化）按同样的定义计算，作对比。模糊的精确正确率和 top-5 正确率在构造上为 1，只作参照。
    - 每张图对它的 196 个 token 取平均，再按图片 bootstrap。
  - **E-C2-2 探针的平均预测分布**：每层把全部测试 token 的 P 取平均，得到 196 个位置上的平均概率（完全无偏时每个位置都是 1/196）。报告：
    - 它与该层模型平均图（R0）的 Pearson 和 Spearman 相关；
    - 它与“离中心近”（离中心距离的相反数）的相关；
    - 最大值与 1/196 之比；
    - 与均匀分布的 KL 散度；
    - 中央 6×6 区域得到的概率（面积占比 36/196 = 18.4%）。
    - 区间：按图片重抽样后重新求平均分布，再算相关。
  - **E-C2-3 在 ImageNet-S 上 C2 把分数搬到了哪里**（第 9–12 层合并，与 v5 的 C2、R0、同等模糊定义相同，全部 12,419 张）。每张图计算：
    - 物体占比：有效图块中物体图块所得分数之和 ÷ 有效图块分数之和。“从物体移到背景的分数”= R0 的物体占比 − C2 的物体占比（正数表示移到了背景）。
    - 按离中心的距离分组（⌊距离⌋ = 0, 1, …, 9 个图块），每组得到总分数的比例，C2 与 R0 的差。
    - (C2 − R0) 与模型平均图（第 9–12 层 R0 平均图之和）的 Pearson、Spearman 相关，以及与“离中心近”的相关。
    - 同等模糊（模糊 − R0）同样计算，作对比。
  - **统计**：按图片配对 bootstrap，1,000 次，种子 0，95% 百分位区间（与 B10 相同）。
  - **两个假设的描述性标准**（只用于讨论，不是已登记的预测）：
    - **H-a 探针的错误主要是远距离错误**：第 9–12 层，三个模型的“错误中的远距离比例”都 > 0.5（区间下限 > 0.5）记为“支持”；都 < 0.5（区间上限 < 0.5）记为“不支持”；其余记为“部分支持”。另外报告这一比例与同等模糊的差。
    - **H-b 探针自带与图片无关的位置偏好**：第 9–12 层，三个模型的平均预测分布都满足两条——最大值至少是 1/196 的 2 倍，且与模型平均图的 Pearson 相关 ≥ 0.5、区间下限 > 0——记为“支持”；三个模型都不满足记为“不支持”；其余记为“部分支持”。E-C2-3 中 (C2 − R0) 与平均图的相关作为旁证：均值 > 0 且区间不含 0。
  - **ClickMe 平滑**：只整理已有数字，不新跑。列出同等模糊、C2、另一种修正顺序（R_all_alt）相对 R0 在 ClickMe 和同距离富集上的变化方向（`experiments/2026-11-05_v5_analysis/correct_tests.csv`、`a7_order.csv`），说明 ClickMe 是否奖励平滑。
