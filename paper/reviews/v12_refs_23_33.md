## 逐条字段与引文用途审查

### [23] Raghu et al., 2021 — ✅ 通过

- **官方来源：** [NeurIPS proceedings](https://proceedings.neurips.cc/paper/2021/hash/652cf38361a209088302ba2b8b7f51e0-Abstract.html)及[论文 PDF](https://proceedings.neurips.cc/paper_files/paper/2021/file/652cf38361a209088302ba2b8b7f51e0-Paper.pdf)。
- **字段：** 五位作者按 Maithra Raghu、Thomas Unterthiner、Simon Kornblith、Chiyuan Zhang、Alexey Dosovitskiy 排列；题名、NeurIPS 2021 均与 Bib 一致。Bib 未给页码或 DOI，NeurIPS 官网条目亦未要求；属于可选补全。
- **论断适配：** §2.2 中与 Brunner 并列支持“contextual mixing need not erase token-identity or input-location information”。该论文明确分析 ViT 对输入空间信息的保留；“token identity”主要由并列的 Brunner 承担。联合引用的表达可接受，但若要更精确，可分成两句分别挂引用。

### [24] Ramsauer et al., 2021 — ✅ ICLR 会议版通过；勿混用版本

- **官方来源：** [ICLR 2021 会议页面](https://iclr.cc/virtual/2021/poster/2657)列 13 位作者，依次为 Ramsauer、Schäfl、Lehner、Seidl、Widrich、Gruber、Holzleitner、Adler、Kreil、Kopp、Klambauer、Brandstetter、Hochreiter；这与当前 Bib **完全一致**。会议年份和题名亦一致。
- **版本差异：** [arXiv:2008.02217](https://arxiv.org/abs/2008.02217)与作者实验室站点上出现不同的旧版作者名单，包含 Pavlović、Sandve、Greiff 等。当前 Bib 标的是 **ICLR 2021**，故应用 ICLR 官方会议记录判断作者，不以旧 arXiv 名单覆盖。
- **论断适配：** §2.1 “softmax attention connects to modern Hopfield memory”与 ICLR 摘要中现代 Hopfield update 和 Transformer attention 等价的说明一致。这里说的是一种数学联系，没有冒充本论文新贡献。
- **建议：** 保留当前字段。若未来加入 URL，选 ICLR 会议记录或其最终论文；避免将会议版题名/venue 与旧版 arXiv 作者混合。

### [25] Schlag et al., 2021 — ✅ 通过

- **官方来源：** [PMLR ICML 2021 论文](https://proceedings.mlr.press/v139/schlag21a.html)及[论文 PDF](https://proceedings.mlr.press/v139/schlag21a/schlag21a.pdf)。
- **字段：** Imanol Schlag、Kazuki Irie、Jürgen Schmidhuber；标题完全一致；ICML 2021、PMLR 139:9355–9366。Bib 的 9355–9366 正确；卷 139 未写在本条，属可选格式补齐。
- **论断适配：** 摘要直接给出线性化 self-attention 与 fast-weight controller 的形式等价；§2.1 使用“Linear attention admits a fast-weight-programming interpretation”准确，没有把证明扩展到一般 softmax attention。

### [29] Wen et al., 2026 / MiTA — ⚠️ 版本间与版本内作者顺序冲突

- **版本证据：** [arXiv v3](https://arxiv.org/abs/2602.01219v3)和 [v4](https://arxiv.org/abs/2602.01219v4)题名为 *MiTA Attention: Efficient Fast-Weight Scaling via a Mixture of Top-k Activations*；[v5](https://arxiv.org/abs/2602.01219v5)与[当前 v6](https://arxiv.org/abs/2602.01219v6)题名为当前 Bib 的 *Mixture-of-Top-k Attention: Efficient Attention via Scalable Fast Weights*，v6 修改日期为 2026-09-27。Bib 题名与 v5/v6 一致，不能回填 v3/v4 题名而保留新版设定。
- **作者冲突：** arXiv v3/v4 PDF 及 v5/v6 **网页 citation metadata** 都按 Wen、Huang、Meng、He、Li 排列；[作者维护的 GitHub 推荐 BibTeX](https://github.com/QishuaiWen/MiTA)也同序，因此当前 Bib 有正式元数据依据。但直接读取[arXiv v6 PDF 首页](https://arxiv.org/pdf/2602.01219v6)却显示 Wen、Huang、**He、Meng**、Li。最新 HTML 论文正文亦如此。这是同一版本网页元数据与 PDF 正文之间的真实冲突，不能推断谁是最终会议版作者顺序。作者仓库称 NeurIPS 2026 已录用，并链接 [OpenReview 投稿](https://openreview.net/forum?id=gIcv8jfze7)，但本次 OpenReview 页面/API/PDF 直接读取返回不可用/403，无法独立确认最终正式 proceedings 的名单。
- **论断适配：** arXiv v3 与 v6 摘要都明确把 attention 看作输入诱导的 two-layer fast-weight MLP；v6 进一步提出 scalable routing/compression 的 MiTA。§2.1 的 attribution 及 Appendix A 所说作者放出的 MiTA-DeiT checkpoint 有[官方代码库及 model zoo](https://github.com/QishuaiWen/MiTA)支持。现有正文没有声称 MiTA 提出本论文的分析框架。
- **建议：** 当前证据不足以把 Bib 作者顺序判为确定错误；保留现状并标注待核。提交前若能获取正式 NeurIPS 2026/OpenReview 可读 BibTeX，以其 final record 统一题名、作者顺序与 venue；若明确引的是 arXiv v6，则在正文或 reference 指定版本，并决定以其 PDF 首页或 metadata 为权威，绝不拼接版本。具体 checkpoint 的 release/commit 可在复现文件中单独固定，不靠论文题名代替。

### [30] Wiegreffe & Pinter, 2019 — ✅ 通过

- **官方来源：** [ACL Anthology 正式条目](https://aclanthology.org/D19-1002/)及其[官方 BibTeX](https://aclanthology.org/D19-1002.bib)，[Crossref DOI 记录](https://api.crossref.org/works/10.18653%2Fv1%2FD19-1002)先行查询成功，三者作者、题名、EMNLP-IJCNLP 2019、11–20、`10.18653/v1/D19-1002` 一致。
- **论断适配：** 该文直接回应 Jain & Wallace 的“Attention is not Explanation”命题，提出依赖解释定义与模型整体的不同判断；§2.2 的“attention’s explanatory role remains debated”有直接支持。注意其主要实验场景为 NLP/RNN，正文未把其实证结论泛化为 ViT 定论。

### [31] Wightman, 2019 / timm — ✅ 当前 PDF 软件引用通过；⚠️ DOI 元数据版本漂移

- **官方来源：** [维护者 GitHub 仓库的 Citing BibTeX](https://github.com/huggingface/pytorch-image-models)与[CITATION.cff](https://github.com/huggingface/pytorch-image-models/blob/main/CITATION.cff)均给出 Ross Wightman、*PyTorch Image Models*、2019、GitHub repository 和 `10.5281/zenodo.4414861`。v12 **PDF 实际打印** Ross Wightman (2019), *PyTorch Image Models*, GitHub repository 和项目 URL，**没有打印 DOI**。
- **DOI 核验：** [Crossref `/works` 查询](https://api.crossref.org/works/10.5281%2Fzenodo.4414861)返回 404；该 DOI 由 **DataCite** 注册，不能据 Crossref 404 判无效。[DataCite 官方记录](https://api.datacite.org/dois/10.5281/zenodo.4414861)返回 200，[DOI 解析](https://doi.org/10.5281/zenodo.4414861)指向 Zenodo。当前 DataCite concept DOI 记录显示 `rwightman/pytorch-image-models: v0.8.10dev0 Release`、2023-02-07、Ross 及多位贡献者，和维护者推荐的通用项目引用处于**不同元数据粒度**。当前 PDF 的作者/年份/项目 URL 没有打印错误。
- **论断适配：** Appendix A 使用本项说明模型由 timm 获取，仓库确实是 timm 官方项目；精确 checkpoint 名称与预处理须由本项目配置/固定修订记录证明，通用 2019 软件引用不证明具体权重字节。
- **建议：** 保持 PDF 当前通用项目引用可接受。若课程或投稿要求 DOI 与参考条目逐字段一致，可在 Bib 中去掉通用 concept DOI、改以维护者推荐的 GitHub 引用为准，或另选与实际使用 `timm` 版本对应的 Zenodo **version DOI**；若未确认实际 release，不应猜版本 DOI。这是可追溯元数据问题，优先级低于 MiTA 作者顺序。

### [32] Zhou et al., 2016 / CAM — ✅ 通过

- **官方来源：** [CVF CVPR 2016 正式条目](https://openaccess.thecvf.com/content_cvpr_2016/html/Zhou_Learning_Deep_Features_CVPR_2016_paper.html)；[Crossref DOI](https://api.crossref.org/works/10.1109%2FCVPR.2016.319)可解析。作者 Bolei Zhou、Aditya Khosla、Agata Lapedriza、Aude Oliva、Antonio Torralba，题名、2016、2921–2929 与 Bib 一致。原 Bib 无 DOI 是可选缺项。
- **论断适配：** CAM 用分类器权重给卷积特征图赋予类别贡献，支持 §2.2 “like CAM’s output weighting”的类比。CAM 的 class-specific linear weights 不是 ViT `\|W_O v\|`，现稿只说类比，没有声称公式等价；如果以后扩写 related work，应把这一区别写清楚。

### [33] Zhu et al., 2024 / SNNA — ✅ 通过

- **官方来源：** [IOS Press 正式文章](https://ebooks.iospress.nl/doi/10.3233/FAIA240520)及[官方卷 392](https://ebooks.iospress.nl/doi/10.3233/FAIA392)，[Crossref DOI 查询](https://api.crossref.org/works/10.3233%2FFAIA240520)，[Manchester 机构记录](https://research.manchester.ac.uk/en/publications/noise-free-explanation-for-driving-action-prediction)。五位作者的姓名、顺序、题名、ECAI 2024、Frontiers in Artificial Intelligence and Applications 392:451–458、DOI `10.3233/FAIA240520` 与 Bib 一致。Crossref 返回 `book-chapter`、页码空白是其条目稀疏，不推翻出版方明确的 451–458。
- **论断适配：** 出版方摘要明确说 SNNA 将 attention 乘以 transformed value vector norm，再加 attention gradient 和扰动平均。§2.2、§3.2 与 Appendix B 只称“norm-weighted component/shared component”，并明确自己的聚合/后续计算不同，引用范围准确；不可把本文 C3 称为 SNNA 或等同其完整算法。
