# Project guide

Paper v8 companion code: **Is It the Model or the Reading? A Fast-Weight View of ViT Attention Maps**, Hongbo Huang.
Work on `paperv8`, branched from `release/v1` at 7477ad5. Open a PR against `release/v1`; do not merge automatically.
Keep `main` and `study/v5` unchanged. The author authorised synchronising `paper/` with the supplied v8 package.

This stage is release engineering, paper/code consistency and artifact verification. Experiments are complete.
Do not run GPU experiments, train models/probes, regenerate original inference outputs or alter scientific protocols.
Keep original weights, definitions, seeds, splits, methods, preprocessing and batch sizes. ClickMe other-image
pairing is batch-dependent (`roll(1)`). Tests with synthetic data are CPU software checks, not new research runs.

## Entry points

```bash
python -m pytest -q
python scripts/validate_release.py --strict --rebuild --archive-check --report build/verification.json
bash reproduce/from_outputs.sh
python scripts/export_release.py --output dist/course_code.zip
```

Use Python 3.12 with pinned CPU dependencies. Rebuilds require a fresh output directory, default `build/rebuilt/`.
Never rebuild over `outputs/`, `results/`, `figures/` or author-maintained `paper/` assets. Preserve ignored local
writing materials and unrelated untracked files. Keep credentials, external datasets/checkpoints and style files out of Git.

## Evidence and validation

`docs/preregistration.md` preserves historical text, dates and P1-P7 rules, then maps v8 R1-R3. Individual
diagnosis/correction correspondence remains post hoc. `docs/evidence.json` and `docs/reproduce.md` map paper items.
`docs/provenance/` contains authentic records and immutable fingerprints. Unknown historical fields stay unknown.
Historical GPU checks certify earlier revisions only. Historical register full-validation accuracy/reduction is
supplied as source evidence and is not regenerated by the active pipeline. GPU scripts are optional future pathways.

Numeric CPU rebuild tolerance: absolute 1e-12, relative zero; counts, labels, selected indices and verdicts exact.
Generated LaTeX tables must be byte-identical; rendering differences are assessed separately. Scientific implementation
ASTs and config values are fingerprinted; documentation edits may change docstrings/comments only.
Archive unused history under `archive/`, excluded by Git export; essential evidence remains active for course ZIPs.
Exports use `.git_archival.txt` for the exact source revision. Commit verified changes by purpose; never force-push.
